# Superpowers Engineering Discipline

Apply this checklist throughout every CodexHub round.

Inputs:

- GSD Spec, GStack Plan, and current git state.
- Known risks and verification requirements.

Process:

- Work in small steps.
- Prefer tests first where practical.
- Apply YAGNI and avoid unrelated refactors.
- Keep shared abstractions DRY without premature framework work.
- Use verification evidence instead of unsupported claims.
- Start and finish with a clean git state unless preserving explicit user changes.
- Do not add unreviewed live automation.

Output:

- A Superpowers Checklist in the round plan.
- Verification evidence and clean-scope confirmation in the final summary.
