# M54.6 App Server Approval And Drift Hardening Runbook

Purpose:

- Rehearse approval waiting and protocol drift blocking before real App Server
  dispatch is connected.

## Expected Behavior

The adapter must:

- Block approval bridge helpers before initialize.
- Ingest approval request events only as metadata.
- Set `silentApprovalAllowed` to `false`.
- Set `rawProposalStored` and `approvalSecretStored` to `false`.
- Return decision hashes and counts, not raw decision labels.
- Create protocol drift reports from baseline/observed hashes and method counts.
- Block live dispatch for unknown or incompatible drift.

## Operator Checks

Before entering M55:

1. Run `pnpm nx test codex-app-server-adapter`.
2. Run `pnpm nx build codex-app-server-adapter`.
3. Run `pnpm nx lint codex-app-server-adapter`.
4. Run `pnpm verify:foundation`.
5. Confirm approval bridge outputs contain no raw proposal, request id,
   lifecycle id, decision label, path, prompt body, file body, or diff body.
6. Confirm protocol drift outputs contain no raw generated schema or JSONL
   transcript.

## Stop Conditions

Stop the round if:

- Approval bridge records silently approve or decline requests.
- Approval records expose raw proposals, commands, files, diffs, paths, or
  decision labels.
- Unknown or incompatible protocol drift does not block live dispatch.
- The adapter starts a real App Server process before governance wiring.

## Extending Later

Use this order:

1. M55 observes Codex Desktop/Electron and OS health read-only.
2. M56 schedules accounts, clients, leases, and worktrees.
3. M57 connects orchestrator preflight to App Server dispatch.
4. Live dispatch remains blocked by policy, approval, evidence, audit, quota,
   and drift checks.

## Closeout Gates

Every follow-up that touches this adapter must run:

- Focused tests for touched packages.
- Focused build for touched packages.
- `pnpm scaffold:health`
- `pnpm audit:boundaries`
- `pnpm audit:sqlite-isolation`
- `pnpm audit:no-live-automation`
- `pnpm audit:skills`
- `git diff --check`

Run `pnpm verify:foundation` at every major-stage closeout.

## Rollback

If approval or drift helpers expose raw private data or allow live dispatch
without review, revert the M54.6 commit and return to the M54.5 lifecycle
metadata baseline.
