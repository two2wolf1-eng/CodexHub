# M59.1 Task Closure Contracts Runbook

Purpose:

- Provide the entry checklist for M59 store and kernel work.

## Operator Checks

1. Confirm M59 closure records use only metadata, hashes, counts, statuses,
   evidence refs, and audit ids.
2. Confirm branch publish and draft PR closure are dry-run only.
3. Confirm `CodexTaskRun` CI and closure writeback fields do not include raw
   diff, path, PR body, command body, or remote payload.

## Stop Conditions

Stop before M59.2 if:

- Any closure schema allows live remote write.
- Any closure schema stores raw prompt, diff, path, body, token, cookie,
  session, MFA, storage, or PR body.
- Focused contracts verification or static audits fail.

## Next Round

for the M59 closure projections.
