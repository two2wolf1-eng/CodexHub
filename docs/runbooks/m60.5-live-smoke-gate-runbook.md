# M60.5 Live Smoke Gate Runbook

Purpose:

- Record an approval-backed live smoke canary gate only after production
  readiness metadata is green.

## Operator Checks

1. Confirm a readiness gate exists and has `status: ready`.
2. Confirm the readiness gate has `liveSmokeAllowed: true`.
3. Provide approval metadata before calling the live smoke gate.
4. Treat missing approval as `approval_waiting`, not as an error to bypass.
5. Treat failed or blocked live smoke canary runs as high-risk live task
   blockers.

## Stop Conditions

Stop if:

- The route starts a process, network probe, App Server call, Electron/CDP
  connection, Browser action, or GitHub write.
- A live smoke gate succeeds without approval metadata.
- A blocked readiness gate can create live-smoke records.
- A response contains raw prompt, diff, path, body, schema, target, audit data,
  canary output, token, cookie, session, MFA, or storage.

## Recovery

- Remove unsafe live-smoke canary records from downstream projections.
- Recreate the gate through a ready readiness gate with approval metadata.
- Re-run Supervisor tests and static audits before enabling any downstream live
  task.
