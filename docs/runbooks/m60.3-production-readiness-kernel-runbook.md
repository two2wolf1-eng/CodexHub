# M60.3 Production Readiness Kernel Runbook

Purpose:

- Derive production readiness records from safe canary, drift, and audit
  metadata before any Supervisor or live-smoke integration consumes them.

## Operator Checks

1. Confirm canary task seeds become hashes before records leave the kernel.
2. Confirm canary failure or blocker status sets high-risk live task blocking.
3. Confirm unknown or incompatible drift sets high-risk live task blocking.
4. Confirm readiness is only `ready` when canaries pass, drift is nonblocking,
   and an audit export summary exists.
5. Confirm live smoke remains a readiness flag requiring downstream approval.

## Stop Conditions

Stop if:

- Kernel records include raw canary output, raw schema, raw target data, raw
  audit body, prompt, diff, path, token, cookie, session, MFA, or storage.
- A failed canary or unknown drift does not block high-risk live work.
- A readiness gate is treated as direct execution authority.

## Recovery

- Drop unsafe derived records from downstream store projections.
- Recreate projections from hashed metadata only.
- Re-run focused production GA kernel tests and audits before continuing.
