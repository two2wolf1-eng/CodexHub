# M75.5 Real Rehearsal Acceptance Runbook

## Operator Checklist

1. Confirm M75 runtime gates are intentionally enabled for the current machine.
2. Confirm the referenced surface and operation manifest already exist in the M74/M75 registries.
3. Run the M75 rehearsal first and inspect evidence/audit ids.
4. Record the real acceptance only after the child run proves whether a live client boundary was reached.
5. Treat missing evidence, missing audit, or uncertain client state as `readiness_blocked`.

## Do Not

- Do not paste selectors, endpoint URLs, scripts, prompts, DOM, network bodies, cookies, session tokens, passwords, or MFA material into the request.
- Do not use M75.5 to substitute for child operation approval or authority.
- Do not mark an admin write as verified unless the post-write state was read back through a registered surface.
