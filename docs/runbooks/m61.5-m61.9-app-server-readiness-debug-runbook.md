# M61.5-M61.9 Runbook

## Operator Steps

1. Use App Server rate limits as the first machine-readable source candidate.
2. Require protocol compatibility before considering a live read.
3. Do not start a thread or turn during quota readiness debug.
4. Store only method counts, source hashes, statuses, summaries, evidence refs, and audit ids.

## Failure Handling

- Not initialized: return a blocked source probe.
- Logged out: create a human checkpoint.
- Quota unavailable: mark source unknown and keep scheduling blocked.
- Protocol drift: block live read.
- Process blocked: keep the report at `needs_adapter` or `manual_checkpoint`.
