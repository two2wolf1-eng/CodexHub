# M59.3 Task Closure Kernel Runbook

Purpose:

- Guide later Supervisor integration of task closure projections.

## Operator Checks

1. Call the task closure kernel with already-summarized metadata only.
2. Provide path hashes and diff hashes, not raw paths or diff bodies.
3. Treat branch publish and draft PR outputs as dry-run metadata.
4. Persist resulting child projections and task-run writeback through store-core
   repositories.

## Stop Conditions

Stop integration if:

- The caller passes raw diff, raw path, raw prompt, raw body, PR body, token,
  cookie, session, MFA, or storage contents.
- A route calls GitHub or verification adapters directly.
- A closure projection enables live remote write.

## Next Round

M59.4 should add Supervisor read-only and POST closure shells that use the
kernel and store projections without direct adapter calls.
