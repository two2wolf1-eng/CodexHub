# M54.4 App Server Account And Rate Limits Runbook

Purpose:

- Rehearse App Server account and rate-limit reads as metadata-only projections.

## Expected Behavior

The adapter must:

- Block account and rate-limit reads before initialize.
- Send `account/read` and receive a response over fixture JSONL transport.
- Return a `CodexAccountBinding` with hashed account/workspace identifiers.
- Send `account/rateLimits/read` and receive a response over fixture JSONL
  transport.
- Return a `QuotaSnapshot` with counts and hashed reset metadata.
- Return only wire summaries and contract-backed metadata records.

## Operator Checks

Before starting M54.5:

1. Run `pnpm nx test codex-app-server-adapter`.
2. Run `pnpm nx build codex-app-server-adapter`.
3. Run `pnpm nx lint codex-app-server-adapter`.
4. Confirm successful account/quota tests contain no raw account ids, email,
   workspace ids, reset times, request ids, or response bodies.
5. Confirm real App Server process launch remains disabled.

## Stop Conditions

Stop the round if:

- Account or quota helpers return raw account identifiers, emails, workspace
  identifiers, reset timestamps, request ids, or response bodies.
- Reads can run before initialize.
- Reads grant authority for command execution, file mutation, or task dispatch.
- The adapter starts a real process before M54.6 drift and approval gates.

## Extending Later

Use this order:

1. M54.5 adds thread, turn, and event helpers.
2. M54.6 adds approval bridge and protocol drift runtime checks.
3. M56 consumes account/quota status for scheduling.
4. M57 dispatches through orchestrator governance.

## Closeout Gates

Every M54 adapter follow-up must run:

- Focused tests for touched packages.
- Focused build for touched packages.
- `pnpm scaffold:health`
- `pnpm audit:boundaries`
- `pnpm audit:sqlite-isolation`
- `pnpm audit:no-live-automation`
- `pnpm audit:skills`
- `git diff --check`

Run `pnpm verify:foundation` at M54 major-stage closeout.

## Rollback

If account/quota reads expose raw private data or bypass initialize, revert the
M54.4 commit and return to the M54.3 adapter shell.
