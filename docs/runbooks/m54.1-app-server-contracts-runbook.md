# M54.1 Codex App Server Contracts Runbook

Purpose:

- Use the M54 contracts as the only shared language for App Server wire,
  thread, turn, event, approval, and protocol drift metadata.

## Expected Behavior

The contracts must:

- Store wire observations as hashes, summaries, counts, and status.
- Store thread and turn mirrors without raw paths, prompts, or response bodies.
- Store event summaries without raw event payloads or deltas.
- Store approval bridge records without command/file payloads, approval secrets,
  or silent approval authority.
- Store protocol drift reports as generated-schema hashes and status counts.
- Block live dispatch when protocol drift is unknown or incompatible.

## Operator Checks

Before starting M54.2:

1. Run `pnpm nx test contracts`.
2. Run `pnpm nx build contracts`.
3. Confirm every new M54 store table maps exactly to one M54 contract.
4. Confirm persistence tests serialize and parse through the public schemas.
5. Confirm raw prompt, diff, path, body, token, cookie, session, MFA, storage,
   command payload, file payload, approval secret, and raw schema fields are
   rejected.

## Stop Conditions

Stop the round if:

- A new App Server record stores raw JSONL payloads, event bodies, deltas,
  prompts, paths, diffs, command payloads, file payloads, tokens, cookies,
  sessions, MFA data, approval secrets, or raw schemas.
- A contract lets unknown or incompatible protocol drift proceed without an
  explicit live-dispatch block.
- A route, UI, CLI, MCP tool, or test calls an App Server adapter directly.
- SQLite runtime bindings appear outside `packages/store-sqlite`.

## Extending Later

Use this order:

1. M54.2 adds store repositories and SQLite tables for the six record types.
2. M54.3 adds transport and initialize lifecycle records.
3. M54.4 maps account and rate-limit reads into existing account/quota
   contracts.
4. M54.5 mirrors threads, turns, and events through these schemas.
5. M54.6 wires approval bridge and drift detection before any live dispatch.

## Closeout Gates

Every M54 contract/store follow-up must run:

- Focused tests for touched packages.
- Focused build for touched packages.
- `pnpm scaffold:health`
- `pnpm audit:boundaries`
- `pnpm audit:sqlite-isolation`
- `pnpm audit:no-live-automation`
- `pnpm audit:skills`
- `git diff --check`

Run `pnpm verify:foundation` at M54 major-stage closeout.

## Rollback

If the M54 contracts are too permissive or leak raw private data, revert the
M54.1 commit before adding store persistence.
