# M55.4 Codex Desktop Health Reconciliation Runbook

Purpose:

- Convert existing metadata from desktop, App Server, quota, account, and
  workspace records into diagnosis hints.

## Expected Behavior

Reconciliation must:

- Mark degraded or drifted App Server metadata as `app_server_unresponsive`.
- Mark exhausted or blocked quota metadata as `quota_depleted`.
- Mark unverified/disabled/blocked account metadata as login problems.
- Mark mismatch account metadata as `wrong_account`.
- Mark missing or mismatched workspace metadata as `workspace_mismatch`.
- Mark unresponsive UI metadata as `desktop_ui_frozen`.

## Operator Checks

Before M55.5:

1. Run `pnpm nx test electron-cdp-kernel`.
2. Run `pnpm nx build electron-cdp-kernel`.
3. Run `pnpm nx lint electron-cdp-kernel`.
4. Confirm reconciliation output contains only hints, booleans, counts, hashes,
   and summaries.
5. Confirm no recovery, login, logout, UI, command, or file action is triggered.

## Stop Conditions

Stop if:

- Reconciliation mutates account, workspace, process, UI, or file state.
- Hints are treated as proof of task success.
- Raw App Server, quota, account, path, prompt, diff, network body, token,
  cookie, session, MFA, or storage data appears in public output.

## Extending Later

Use this order:

1. M55.5 runs full hardening and verify.
2. M56 consumes hints for scheduler scoring.
3. M57 routes failing tasks to diagnosis, not false success.
