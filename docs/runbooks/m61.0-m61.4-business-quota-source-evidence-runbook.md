# M61.0-M61.4 Runbook

## Operator Steps

1. Confirm the worktree is clean before starting quota readiness debug.
2. Run foundation verification.
3. Treat App Server `account/rateLimits/read` as the preferred machine-readable candidate.
4. Treat Business credits, spend controls, and role documentation as source evidence, not live authority.
5. Do not ingest raw identity, browser state, request payloads, response payloads, profile paths, or page text.

## Expected Output

- Metadata-only source probes.
- Field evidence matrix with count, status, hash, summary, and forbidden classifications.
- Human checkpoint when permissions are not established.

## Stop Conditions

- Any request for credential or browser-state collection.
- Any attempt to use UI text extraction as a machine data source.
- Any route or test directly calling a capability adapter as authority.
