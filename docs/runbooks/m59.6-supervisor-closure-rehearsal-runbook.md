# M59.6 Supervisor Closure Rehearsal Runbook

Purpose:

- Provide operator checks for Supervisor task closure route rehearsal.

## Operator Checks

1. Create or select a completed `CodexTaskRun` metadata record.
2. Submit closure metadata through `POST /tasks/:taskId/closure`.
3. Inspect `closureStatus`, `ciStatus`, `blockerCount`, `dryRunOnly`, and
   `liveRemoteWriteAllowed`.
4. Inspect `GET /tasks/closures` for aggregate dry-run and remote-write counts.
5. Treat `completed` as a review/closure readiness signal only; GitHub publish
   and draft PR remain dry-run and approval-gated.

## Stop Conditions

Stop if:

- Supervisor returns `completed` for empty diff, failed verification, blocked
  review, approval waiting, or failed CI.
- `remoteWritesAllowed` is greater than zero.
- Route output includes raw diff, raw path, PR body, token, cookie, session,
  MFA, storage, or local-control token data.
- Supervisor starts calling adapters directly from the route.
