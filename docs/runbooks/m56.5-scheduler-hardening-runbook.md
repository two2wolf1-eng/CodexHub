# M56.5 Scheduler Hardening Runbook

Purpose:

- Close M56 and define the operational gate before M57 dispatch work.

## Expected Behavior

Before M57 starts:

- `pnpm verify:foundation` must pass.
- Scheduler readiness must remain metadata-only.
- Supervisor GET routes may show readiness, but must not grant authority.
- Leases must store target and holder hashes only.

## Operator Checks

1. Run `pnpm verify:foundation`.
2. Confirm all 42 projects pass lint/test/build.
3. Confirm `pnpm audit:no-live-automation` passes.
4. Confirm Supervisor `/accounts`, `/clients`, and `/tasks` expose only
   scheduler metadata.
5. Confirm no App Server adapter dispatch path is introduced before M57.

## Stop Conditions

Stop if:

- Full foundation verification fails.
- Scheduler readiness is treated as task success.
- A GET route grants execution authority.
- A lease stores raw path/account/holder data or a secret.
- Raw prompt, diff, path, body, token, cookie, session, MFA, storage, command
  line, account identifier, or profile path appears in public responses.

## M57 Entry Gate

M57 may begin only after:

- M56.5 full verification passes.
- Worktree lease is required by task preflight.
- Failure paths write diagnosis records.
- App Server dispatch remains behind policy, approval, evidence, and audit.

## Closeout Gates

- `pnpm verify:foundation`
- `git diff --check`
- Independent M56.5 docs commit.
