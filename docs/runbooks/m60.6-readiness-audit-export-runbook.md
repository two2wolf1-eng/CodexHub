# M60.6 Readiness Audit Export Runbook

Purpose:

- Produce a metadata-only audit export summary for production readiness records.

## Operator Checks

1. Call the audit export route only with local-control token and trusted local
   Origin/Host.
2. Confirm `metadataOnly: true`.
3. Confirm `recordCount`, `exportHash`, and `manifestHash` are present.
4. Confirm raw audit records and raw readiness details are not returned.
5. Treat the export summary as evidence, not execution authority.

## Stop Conditions

Stop if:

- A route writes a raw export file or uploads an export.
- Output includes raw audit record bodies, prompt, diff, path, body, schema,
  target, canary output, token, cookie, session, MFA, or storage.
- Audit export summary is used to bypass readiness or approval gates.

## Recovery

- Remove unsafe audit export summaries from downstream projections.
- Regenerate the summary from safe ids/hashes/counts only.
- Re-run Supervisor tests and static audits.
