# M58.1 Diagnosis Recovery Contracts Runbook

Purpose:

- Verify the shared contract layer before implementing M58 kernels.

## Operator Checks

1. Run `pnpm nx test contracts`.
2. Run `pnpm nx build contracts`.
3. Run `pnpm nx lint contracts`.
4. Confirm high-risk recovery records require `dryRunId` and approval.
5. Confirm `liveActionAllowed` remains false.

## Stop Conditions

Stop if:

- A high-risk recovery can be parsed without dry-run and approval.
- A recovery record can enable live execution directly.
- Any contract permits raw prompt, diff, path, body, token, cookie, session,
  MFA, or storage metadata.

## M58.2 Entry Gate

M58.2 may begin after:

- Contracts test/build/lint pass.
- M58.1 docs and commit are complete.

## Workflow Skills Used and Why

- `gsd-spec-driver`: defines gates.
- `gstack-delivery-workflow`: documents handoff to M58.2.
- `superpowers-engineering-discipline`: keeps execution disabled.

## Project Skills Used and Why

- `codexhub-contract-designer`: use for shared contract checks.
- `codexhub-workflow-policy-reviewer`: use for approval gates.
- `codexhub-release-auditor`: use for verification.

## Skills Not Used by Default

- Adapter, Electron/CDP, browser profile, and Playwright QA skills are only
  required when those surfaces change.
