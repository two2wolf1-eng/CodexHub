# M54.2 Codex App Server Store Runbook

Purpose:

- Persist App Server metadata records while keeping all raw protocol content out
  of CodexHub storage.

## Expected Behavior

The store must:

- Save, get, and list App Server wire message summaries.
- Save, get, and list App Server thread mirrors.
- Save, get, and list App Server turn mirrors.
- Save, get, and list App Server event summaries.
- Save, get, and list App Server approval bridge records.
- Save, get, and list App Server protocol drift reports.
- Preserve records across SQLite reopen.
- Filter records by status through the existing metadata query.

## Operator Checks

Before starting M54.3:

1. Run `pnpm nx test store-sqlite`.
2. Run `pnpm nx build store-core`.
3. Run `pnpm nx build store-sqlite`.
4. Confirm no SQLite runtime import appears outside `packages/store-sqlite`.
5. Confirm new App Server records are created by parsing public contracts before
   `saveRecord`.
6. Confirm no raw payload, path, diff, command payload, file payload, approval
   secret, token, cookie, session, MFA, storage, or raw schema can be persisted.

## Stop Conditions

Stop the round if:

- A new store table stores dedicated raw protocol columns.
- A repository accepts raw App Server payloads without a contract parse step in
  the caller.
- SQLite runtime bindings appear outside `packages/store-sqlite`.
- Store code starts an App Server process, connects to Codex Desktop, or
  performs live dispatch.

## Extending Later

Use this order:

1. M54.3 adapter emits metadata records through these repositories in tests.
2. M54.4 maps account and rate-limit reads to existing account/quota records.
3. M54.5 stores thread, turn, and event mirrors through these repositories.
4. M54.6 stores approval bridge and drift reports before dispatch is enabled.
5. M57 uses orchestrator governance to select and persist task runs.

## Closeout Gates

Every M54 store/adapter follow-up must run:

- Focused tests for touched packages.
- Focused build for touched packages.
- `pnpm scaffold:health`
- `pnpm audit:boundaries`
- `pnpm audit:sqlite-isolation`
- `pnpm audit:no-live-automation`
- `pnpm audit:skills`
- `git diff --check`

Run `pnpm verify:foundation` at M54 major-stage closeout.

## Rollback

If App Server persistence stores raw private data or bypasses contract parsing,
revert the M54.2 commit before adding adapter code.
