# M55.3 Allowlisted OS Process Observer Runbook

Purpose:

- Safely summarize OS process metadata for Codex Desktop readiness without
  embedding a real system command in the foundation path.

## Expected Behavior

The observer must:

- Require an injected process enumerator.
- Filter snapshots by an explicit process-name allowlist.
- Store pid, parent pid, executable path, and command line as hashes.
- Store CPU, memory, and duration as rounded metadata.
- Report `unavailable` when no enumerator is provided.

## Operator Checks

Before M55.4:

1. Run `pnpm nx test observer-kernel`.
2. Run `pnpm nx build observer-kernel`.
3. Run `pnpm nx lint observer-kernel`.
4. Confirm no built-in PowerShell/WMI/process-list command exists.
5. Confirm public output contains no raw path, command line, process argument,
   token, cookie, session, MFA, storage, network body, prompt, or diff.

## Stop Conditions

Stop if:

- The observer starts, stops, kills, or mutates a process.
- A real OS enumeration command is added without an explicit boundary review.
- Non-allowlisted process snapshots appear in public output.
- Raw local paths or command lines are returned.

## Extending Later

Use this order:

1. M55.4 reconciles OS process, Electron/CDP, App Server, quota, and login hints.
2. A future real OS enumerator must be added as a separately reviewed boundary.
3. M56 consumes health metadata for client/account scheduling.
