# M55.2 Electron/CDP Local Discovery Projection Runbook

Purpose:

- Convert read-only local discovery inputs into safe Codex Desktop health
  metadata without touching real process or CDP boundaries by default.

## Expected Behavior

The projection must:

- Accept a Codex Desktop process candidate and hash ids, paths, command lines,
  and window titles.
- Accept only loopback debug endpoints.
- Carry target, console, and network summaries as metadata only.
- Emit a Codex Desktop health snapshot with diagnosis hints.
- Leave HTTP, WebSocket, and process boundaries uninvoked.

## Operator Checks

Before M55.3:

1. Run `pnpm nx test electron-cdp-kernel`.
2. Run `pnpm nx test electron-cdp-adapter`.
3. Confirm the projection output contains no raw executable path, command line,
   window title, target title, target URL, WebSocket URL, or network body.
4. Confirm non-loopback endpoints are not projected as trusted endpoints.

## Stop Conditions

Stop if:

- The projection invokes real process, HTTP, or WebSocket boundaries.
- Non-loopback endpoints are accepted.
- Raw path, command line, target URL, network body, token, cookie, session, MFA,
  storage, prompt, diff, or DOM body appears in public output.

## Extending Later

Use this order:

1. M55.3 adds allowlisted OS process observer inputs.
2. M55.4 reconciles health hints.
3. M55.5 runs full hardening and verify.
