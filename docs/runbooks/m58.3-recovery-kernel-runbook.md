# M58.3 Recovery Kernel Runbook

Purpose:

- Verify recovery planning before Supervisor persistence and rehearsal.

## Operator Checks

1. Run `pnpm nx test recovery-kernel`.
2. Run `pnpm nx build recovery-kernel`.
3. Run `pnpm nx lint recovery-kernel`.
4. Run `pnpm audit:no-live-automation`.
5. Confirm high-risk recovery kinds are `needs_human` and approval waiting.

## Stop Conditions

Stop if:

- Any recovery plan enables live action.
- Any recovery plan disables the dry-run requirement.
- Any high-risk recovery avoids approval.
- Any output stores raw prompt, diff, path, body, or command content.

## M58.4 Entry Gate

M58.4 may begin after:

- Recovery test/build/lint pass.
- Static audits pass.
- M58.3 docs and commit are complete.

## Workflow Skills Used and Why

- `gsd-spec-driver`: defines stop conditions.
- `gstack-delivery-workflow`: documents handoff to Supervisor integration.
- `superpowers-engineering-discipline`: keeps recovery disabled.

## Project Skills Used and Why

- `codexhub-architecture-planner`: use for package boundary checks.
- `codexhub-contract-designer`: use for recovery schema checks.
- `codexhub-workflow-policy-reviewer`: use for approval gates.
- `codexhub-release-auditor`: use for verification.

## Skills Not Used by Default

- Adapter, Electron/CDP, browser profile, and Playwright QA skills are only
  required when those surfaces change.
