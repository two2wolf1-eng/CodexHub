# M59.8 CI Mirror Closure Writeback Runbook

Purpose:

- Provide operating checks for CI status writeback through M59 closure metadata.

## Operator Checks

1. Submit closure metadata with `ciStatus: pending` while CI is still running.
2. Submit a later closure metadata update with `ciStatus: passed` or `failed`.
3. Inspect `GET /tasks` and `GET /tasks/closures` for task-run and closure
   projection status.
4. Confirm `closureSummaryHash` exists and response bodies remain metadata-only.

## Stop Conditions

Stop if:

- CI mirror tries to call a CI provider or starts a process.
- Task-run writeback stores raw diff, path, PR body, command output, token,
  cookie, session, MFA, storage, or local-control token.
- Closure projection reports remote writes allowed.
- Pending CI is treated as completed before a passed CI mirror arrives.
