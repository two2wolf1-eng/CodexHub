# M56.4 Supervisor Scheduler Projections Runbook

Purpose:

- Surface scheduler readiness through Supervisor read routes without granting
  execution authority.

## Expected Behavior

Supervisor must:

- Return account scheduler metadata from `/accounts`.
- Return client scheduler metadata from `/clients`.
- Return task preflight readiness metadata from `/tasks`.
- Keep `dispatchAllowed` and `directAdapterExecutionAllowed` false in these GET
  responses.
- Continue enforcing local-control token and trusted Origin/Host on POST routes.

## Operator Checks

Before M56.5:

1. Run `pnpm nx test supervisor`.
2. Run `pnpm nx build supervisor`.
3. Run `pnpm nx lint supervisor`.
4. Confirm `/accounts`, `/clients`, and `/tasks` do not expose raw account,
   profile, path, task, prompt, or body data.
5. Confirm no route imports or calls an adapter to build scheduler readiness.

## Stop Conditions

Stop if:

- A Supervisor route calls Codex App Server, Browser, Electron, or OS adapters
  directly for scheduler readiness.
- A GET response grants dispatch authority.
- A response includes raw prompt, diff, path, body, token, cookie, session, MFA,
  storage, command line, account identifier, or profile path data.

## Extending Later

Use this order:

1. M56.5 runs concurrent scheduling rehearsal and full verification.
2. M57 consumes Scheduler readiness before task dispatch.
3. Dashboard/UX can render these projections later with read-only controls.
