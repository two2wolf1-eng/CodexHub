# M51.2 Unified Metadata Store Runbook

Purpose:

- Store M51 account, client, task, quota, checkpoint, lease, and evidence
  metadata records without storing raw private payloads.

## Expected Behavior

M51 store users must:

- Parse records through contracts before calling `saveRecord`.
- Store metadata-only JSON payloads in the new SQLite tables.
- Use `listRecords` with safe limits and optional status/dry-run filters.
- Keep raw prompt, diff, path, body, token, cookie, session, MFA, credential,
  browser storage, raw logs, and raw traces out of persisted records.
- Treat SQLite persistence as a projection source, not as adapter authority.

## Operator Checks

Before M51.3 Supervisor work:

1. Run `pnpm nx test store-sqlite`.
2. Confirm `pnpm audit:sqlite-isolation` passes.
3. Confirm no app or package outside `store-sqlite` imports SQLite runtime APIs.
4. Confirm producers parse through M51 contracts before save.
5. Confirm public projections return hashes, summaries, statuses, counts,
   evidence refs, and audit ids only.

## Stop Conditions

Stop the round if:

- A store record contains raw prompt, path, body, token, cookie, session, MFA,
  credential, or browser storage data.
- `store-core` imports SQLite runtime code.
- A Supervisor route calls an adapter directly instead of reading the store.
- A POST route returns request body content instead of hashes/refs.
- Any real browser, account, Codex App Server, GitHub, or admin operation starts
  from store tests.

## Extending In M51.3

Use this order:

1. Read records from the M51 store repositories.
2. Project only safe fields into `/accounts`, `/clients`, and `/tasks`.
3. Persist task create/recover shell records without live dispatch.
4. Preserve M50.4 degraded-store and shared route guard behavior.
5. Add tests for metadata-only responses and no route-to-adapter execution.

## Closeout Gates

Every follow-up M51-M53 sub-round must run:

- Focused tests for touched packages.
- Focused build for touched packages.
- `pnpm scaffold:health`
- `pnpm audit:boundaries`
- `pnpm audit:sqlite-isolation`
- `pnpm audit:no-live-automation`
- `pnpm audit:skills`
- `git diff --check`

Run `pnpm verify:foundation` at major-stage closeout.

## Rollback

If store persistence leaks raw private data or breaks SQLite isolation, revert
the M51.2 commit and restore the M51.1 contracts-only baseline before continuing.
