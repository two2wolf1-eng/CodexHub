# M60.8 Production Readiness E2E Runbook

Purpose:

- Prove the production readiness chain can be rehearsed through Supervisor
  fixtures before any live probe is considered.

## Rehearsal Chain

1. Create a ready production readiness rehearsal.
2. Record an approval-backed live-smoke canary gate.
3. Create a metadata-only audit export summary.
4. Create a blocked readiness rehearsal.
5. Confirm blocked readiness prevents live-smoke gate records.
6. Read readiness summary and verify execution remains disabled.

## Expected Results

- Ready readiness returns `liveSmokeAllowed: true`.
- Live smoke gate returns `status: passed` only with approval metadata.
- Audit export returns `metadataOnly: true`.
- Blocked readiness returns `highRiskLiveTaskBlocked: true`.
- Blocked readiness live smoke returns conflict.
- No private fixture seed appears in any response.

## Stop Conditions

Stop if:

- Any E2E step invokes process, network, App Server, Electron/CDP, Browser, or
  GitHub boundaries.
- Live smoke can proceed without approval metadata.
- Blocked readiness can create live-smoke records.
- Raw prompt, diff, path, body, schema, target, audit record, canary output,
  token, cookie, session, MFA, or storage appears in output.
