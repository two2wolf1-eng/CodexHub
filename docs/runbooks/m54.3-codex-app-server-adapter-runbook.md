# M54.3 Codex App Server Adapter Runbook

Purpose:

- Use the App Server adapter package to rehearse JSONL initialize lifecycle
  behavior without starting a real App Server process.

## Expected Behavior

The adapter must:

- Produce a manifest that requires approval by default.
- Produce a dry-run plan that keeps process launch and live dispatch disabled.
- Encode and decode JSONL protocol messages.
- Initialize by sending `initialize`, receiving a response, and sending
  `initialized`.
- Return only wire/session metadata summaries.
- Block duplicate initialize attempts.
- Classify operations before initialize as blocked.

## Operator Checks

Before starting M54.4:

1. Run `pnpm nx test codex-app-server-adapter`.
2. Run `pnpm nx build codex-app-server-adapter`.
3. Run `pnpm nx lint codex-app-server-adapter`.
4. Confirm fixture transport summaries do not expose raw JSONL lines.
5. Confirm real process launch remains disabled.
6. Confirm account and rate-limit helpers use contracts before store writes.

## Stop Conditions

Stop the round if:

- The adapter starts a real process before authority, approval, evidence, audit,
  and drift checks exist.
- Public outputs contain raw JSONL transcripts, private ids, prompts, diffs,
  paths, bodies, command payloads, file payloads, tokens, cookies, sessions, MFA
  data, approval secrets, or raw schemas.
- Supervisor, UI, CLI, MCP tools, or tests call the adapter as an authority
  provider.
- A route bypasses local-control token or trusted Origin/Host checks.

## Extending Later

Use this order:

1. M54.4 adds account and rate-limit helpers.
2. M54.5 adds thread, turn, and event helpers.
3. M54.6 adds approval bridge and protocol drift runtime checks.
4. M56 adds scheduling and leases.
5. M57 routes real dispatch through orchestrator governance.

## Closeout Gates

Every M54 adapter follow-up must run:

- Focused tests for touched packages.
- Focused build for touched packages.
- `pnpm scaffold:health`
- `pnpm audit:boundaries`
- `pnpm audit:sqlite-isolation`
- `pnpm audit:no-live-automation`
- `pnpm audit:skills`
- `git diff --check`

Run `pnpm verify:foundation` at M54 major-stage closeout.

## Rollback

If the adapter stores raw protocol content or starts a real process without the
M54.6 gates, revert the M54.3 commit and return to the M54.2 store baseline.
