# M59.2 Task Closure Store Runbook

Purpose:

- Define checks for using the M59 closure store records in later kernels and
  Supervisor projections.

## Operator Checks

1. Store M59 closure records only through store-core repositories.
2. Keep SQLite bindings inside `packages/store-sqlite`.
3. Persist only ids, hashes, counts, statuses, evidence refs, and audit ids.
4. Treat GitHub branch publish and draft PR records as dry-run metadata unless
   a later approved round explicitly enables remote writes.

## Stop Conditions

Stop before kernel integration if:

- A store record includes raw diff, path, PR body, prompt, token, cookie,
  session, MFA, storage, command body, or response body.
- Supervisor or a kernel imports SQLite runtime directly.
- A route calls a GitHub or verification adapter directly.

## Next Round

M59.3 should add a task closure kernel that projects diff, verification,
review, GitHub dry-run, and CI metadata into the new store records.
