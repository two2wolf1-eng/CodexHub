# M57.6-M57.7 Dispatch Lifecycle Runbook

Purpose:

- Verify and operate the M57 App Server lifecycle shell before Supervisor route
  integration.

## Expected Behavior

The lifecycle should:

- Return the preflight task run unchanged when preflight is blocked.
- Initialize App Server before any thread or turn request.
- Start or resume a thread, then start a turn, then ingest events.
- Mark the task run completed only after a terminal event is observed.
- Write `CodexTaskDiagnosis` for missing App Server controller, initialize
  failure, thread/turn failure, failed event, or stalled event stream.
- Return metadata-only projections and never serialize private JSON-RPC ids,
  raw thread ids, raw turn ids, prompt, diff, path, body, token, cookie,
  session, MFA, or storage.

## Operator Checks

1. Run `pnpm nx test orchestrator-kernel`.
2. Run `pnpm nx build orchestrator-kernel`.
3. Run `pnpm nx lint orchestrator-kernel`.
4. Run `pnpm audit:boundaries`.
5. Run `pnpm audit:no-live-automation`.
6. Confirm successful dispatch tests use in-memory transport unless a separate
   approved live smoke gate is being exercised.

## Stop Conditions

Stop if:

- A task is marked completed without a terminal event.
- Blocked preflight still calls App Server.
- Missing approval, quota depletion, drift, canary failure, or lease conflict is
  bypassed.
- Any route calls an adapter directly.
- Any result serializes raw prompt, diff, path, body, token, cookie, session,
  MFA, storage, raw thread id, raw turn id, or JSON-RPC request id.

## M57.8 Entry Gate

M57.8 may begin after:

- Focused orchestrator test/build/lint pass.
- Boundary and no-live audits pass.
- M57.6/M57.7 release, review, and runbook docs are committed.

## Closeout Gates

- Focused tests/build/lint.
- Static audits.
- Independent M57.6/M57.7 commit.
