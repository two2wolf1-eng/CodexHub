# M60.1 Production Readiness Contracts Runbook

Purpose:

- Provide operator meaning for M60 canary, drift, readiness, and audit export
  contract records.

## Operator Checks

1. Treat failed canary runs as high-risk live task blockers.
2. Treat incompatible or unknown drift gates as high-risk live task blockers.
3. Require approval artifact hashes for any live smoke canary.
4. Store audit export manifests as hashes and counts only.
5. Do not interpret these contracts as execution authority.

## Stop Conditions

Stop if:

- A canary failure does not block high-risk live tasks.
- Drift is unknown or incompatible while live work remains unblocked.
- Live smoke lacks approval.
- Audit export summary contains raw prompt, diff, path, body, token, cookie,
  session, MFA, storage, or raw records.
