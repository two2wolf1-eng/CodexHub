# M61.25-M61.29 Runbook

## M62 Entry Conditions

1. Human confirms role or a metadata-only source proves it.
2. App Server protocol drift is compatible.
3. Canary for account, quota, login, App Server, approval, and worktree is green.
4. Local-control token and trusted origin checks remain enforced.
5. Forbidden path probes remain blocked or verified absent.

## M62 Stop Conditions

- Source unavailable.
- Role insufficient.
- Workspace mismatch.
- App Server unavailable.
- Drift unknown or incompatible.
- Any request to ingest browser persisted state, page text, transport payloads, or raw identity material.

## Closeout Command Set

- `pnpm scaffold:health`
- `pnpm audit:boundaries`
- `pnpm audit:sqlite-isolation`
- `pnpm audit:no-live-automation`
- `pnpm audit:skills`
- `pnpm verify:foundation`
