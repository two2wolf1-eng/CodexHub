# M60.4 Production Readiness Supervisor Runbook

Purpose:

- Let operators inspect and rehearse production readiness projections without
  executing live canaries or calling adapters directly.

## Operator Checks

1. Use `GET /api/production-readiness/summary` to inspect aggregate readiness.
2. Use canary, drift, readiness, and audit list routes for metadata drilldown.
3. Use `POST /api/production-readiness/rehearsals` only with local-control
   token and trusted local Origin/Host.
4. Treat rehearsal output as projection evidence, not execution approval.
5. Stop high-risk live work when readiness is not `ready` or any blocker count
   is nonzero.

## Stop Conditions

Stop if:

- A Supervisor route calls an adapter directly.
- A POST request succeeds without local-control token or trusted Origin/Host.
- A response contains raw canary output, raw schema, raw target, raw audit data,
  raw readiness data, prompt, diff, path, body, token, cookie, session, MFA, or
  storage.
- A blocked readiness gate is treated as authority to run live work.

## Recovery

- Delete or quarantine unsafe store projections.
- Recreate projections through the guarded rehearsal shell using metadata-only
  seeds.
- Re-run Supervisor tests, boundary audits, and no-live automation audit before
  continuing.
