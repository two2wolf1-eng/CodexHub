# M54.5 App Server Thread, Turn, And Events Runbook

Purpose:

- Rehearse App Server task lifecycle metadata without real prompt dispatch.

## Expected Behavior

The adapter must:

- Block thread, turn, and event helpers before initialize.
- Send `thread/start` and project a thread mirror.
- Send `thread/resume` and project a thread mirror.
- Send `turn/start` and project a turn mirror.
- Ingest event notification lines and project event summaries.
- Return only hashes, counts, status, refs, and summaries.

## Operator Checks

Before starting M54.6:

1. Run `pnpm nx test codex-app-server-adapter`.
2. Run `pnpm nx build codex-app-server-adapter`.
3. Run `pnpm nx lint codex-app-server-adapter`.
4. Confirm thread/turn/event outputs contain no raw thread ids, turn ids, item
   ids, paths, prompt bodies, model output bodies, diffs, or request ids.
5. Confirm no test asserts task success without a terminal event.

## Stop Conditions

Stop the round if:

- Thread, turn, or event helpers expose raw lifecycle ids or payload bodies.
- Turn start sends or stores a raw prompt in public results.
- Event ingestion stores deltas, diffs, command payloads, or file payloads.
- The adapter starts a real process before M54.6 drift and approval gates.

## Extending Later

Use this order:

1. M54.6 adds approval bridge and protocol drift checks.
2. M56 consumes thread/client/account readiness for scheduling.
3. M57 persists task runs through orchestrator governance.
4. Real prompt dispatch remains behind policy, approval, evidence, and audit.

## Closeout Gates

Every M54 adapter follow-up must run:

- Focused tests for touched packages.
- Focused build for touched packages.
- `pnpm scaffold:health`
- `pnpm audit:boundaries`
- `pnpm audit:sqlite-isolation`
- `pnpm audit:no-live-automation`
- `pnpm audit:skills`
- `git diff --check`

Run `pnpm verify:foundation` at M54 major-stage closeout.

## Rollback

If thread/turn/event helpers expose raw private data or claim false success,
revert the M54.5 commit and return to the M54.4 account/quota baseline.
