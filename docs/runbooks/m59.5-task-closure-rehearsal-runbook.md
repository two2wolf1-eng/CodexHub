# M59.5 Task Closure Rehearsal Runbook

Purpose:

- Provide operator guidance for interpreting M59 closure rehearsal outcomes.

## Operator Checks

1. Run or inspect the rehearsal scenario for the task closure state.
2. Treat `passed` as eligible for human review and dry-run closure planning
   only.
3. Treat `blocked` as requiring human or project-side resolution before any
   dry-run branch or draft PR step advances.
4. Treat `failed` as requiring CI or verification diagnosis before closure.
5. Confirm `liveRemoteWriteAllowed` and `externalProcessStarted` remain false.

## Stop Conditions

Stop if:

- Empty diff, failed verification, blocked review, or approval waiting reports
  as completed.
- CI passed metadata overrides an earlier closure blocker.
- Rehearsal emits raw prompt, diff, path, body, token, cookie, session, MFA, or
  storage data.
- Rehearsal starts a process or attempts remote GitHub writes.
