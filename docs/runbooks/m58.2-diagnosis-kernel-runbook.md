# M58.2 Diagnosis Kernel Runbook

Purpose:

- Verify the metadata-only diagnosis kernel before recovery planning begins.

## Operator Checks

1. Run `pnpm nx test diagnosis-kernel`.
2. Run `pnpm nx build diagnosis-kernel`.
3. Run `pnpm nx lint diagnosis-kernel`.
4. Confirm output exposes only diagnosis metadata and evidence/audit refs.

## Stop Conditions

Stop if:

- The kernel starts an external process or calls an adapter.
- Diagnosis output includes raw prompt, diff, path, body, token, cookie,
  session, MFA, or storage.
- Required M58 states are not covered by focused tests.

## M58.3 Entry Gate

M58.3 may begin after:

- Diagnosis test/build/lint pass.
- M58.2 docs and commit are complete.

## Workflow Skills Used and Why

- `gsd-spec-driver`: defines verification gates.
- `gstack-delivery-workflow`: documents handoff to recovery planning.
- `superpowers-engineering-discipline`: keeps the kernel action-free.

## Project Skills Used and Why

- `codexhub-architecture-planner`: use for package ownership.
- `codexhub-contract-designer`: use for diagnosis schema checks.
- `codexhub-workflow-policy-reviewer`: use for metadata-only safety.
- `codexhub-release-auditor`: use for verification.

## Skills Not Used by Default

- Adapter, Electron/CDP, browser profile, and Playwright QA skills are only
  required when those surfaces change.
