# M57.3-M57.4 Orchestrator Preflight Runbook

Purpose:

- Operate and verify the Codex task dispatch preflight before enabling the live
  App Server boundary.

## Expected Behavior

The preflight should:

- Require account, client, profile, thread, worktree, task, and quota leases.
- Require dry-run id, approval artifact, policy approval, compatible protocol
  drift, and a passed canary gate for live App Server dispatch.
- Require an isolated worktree target and keep repository-root writes blocked.
- Return scheduler selection, lease bundle, task run, and optional diagnosis
  metadata only.
- Keep `liveExecution`, `externalProcessStarted`, and adapter execution false.

## Operator Checks

1. Run `pnpm nx test orchestrator-kernel`.
2. Run `pnpm nx build orchestrator-kernel`.
3. Run `pnpm nx lint orchestrator-kernel`.
4. Run `pnpm audit:boundaries`.
5. Run `pnpm audit:no-live-automation`.
6. Confirm serialized preflight output does not include raw profile names,
   worktree paths, prompts, diffs, command bodies, account identifiers, or
   secrets.

## Stop Conditions

Stop if:

- `dispatchAllowed` is true while approval, dry-run, policy, drift, canary, or
  any required lease is missing.
- Any App Server process or adapter call happens during preflight.
- A task run reports `liveExecution: true` before M57.5/M57.6 authority.
- A root repository write is allowed.
- Raw prompt, diff, path, body, token, cookie, session, MFA, storage, account
  identifier, or lease secret appears in output.

## M57.5 Entry Gate

M57.5 may begin after:

- Focused orchestrator tests/build/lint pass.
- No-live audit passes with the narrow App Server session metadata allowlist.
- The preflight result can distinguish ready, waiting approval, quota depleted,
  lease conflict, and drift blocked states.

## Closeout Gates

- `git diff --check`
- Focused tests/build/lint.
- Static audits.
- Independent M57.3/M57.4 commit.
