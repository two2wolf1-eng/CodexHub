# M55.1 Electron/CDP And OS Process Contracts Runbook

Purpose:

- Provide shared contracts for read-only Codex Desktop health and OS process
  metadata before any runtime discovery is connected.

## Expected Behavior

Contracts must:

- Store process names, process ids, paths, and command lines as hashes.
- Store CPU, memory, duration, target counts, console error counts, and network
  failed request counts as metadata only.
- Represent desktop health with booleans and diagnosis hints.
- Reject raw path fields and any unmodeled raw payload fields.

## Operator Checks

Before M55.2:

1. Run `pnpm nx test contracts`.
2. Run `pnpm nx build contracts`.
3. Run `pnpm nx lint contracts`.
4. Confirm `CodexDesktopHealthSnapshotSchema` has diagnosis hints but no raw UI
   payload fields.
5. Confirm `OsProcessMetadataSummarySchema` has hashes and rounded metrics only.

## Stop Conditions

Stop if:

- Any schema accepts a raw executable path or command line.
- Desktop health stores raw DOM, console body, network body, token, cookie,
  session, MFA, storage, prompt, path, or diff data.
- Runtime discovery is added before contracts are committed.

## Extending Later

Use this order:

1. M55.2 adds Electron/CDP read-only discovery helpers.
2. M55.3 adds allowlisted OS process observer helpers.
3. M55.4 adds health reconciliation hints.
4. M55.5 runs hardening and full verification.
