# M61.10-M61.14 Runbook

## Operator Steps

1. Ask the human operator for role confirmation when no metadata source exists.
2. If role is unknown, keep readiness at `manual_checkpoint`.
3. If role is member, only own-quota metadata can be considered.
4. If workspace-level fields are needed, require admin/owner or equivalent analytics evidence.

## Human Checkpoints

- `manual_review_required`: role unknown or analytics unavailable.
- `workspace_select_required`: workspace mismatch.
- `account_select_required`: wrong account metadata.

## Stop Conditions

- Any attempt to infer role by automated UI interaction.
- Any account switch or login operation during M61.
