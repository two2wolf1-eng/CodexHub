# M58.5 Diagnosis Recovery Hardening Runbook

Purpose:

- Close M58 and define the M59 entry gate.

## Operator Checks

1. Confirm `git status --short` is empty before hardening.
2. Run `pnpm verify:foundation`.
3. Confirm recovery plans remain dry-run and approval-gated.

## Stop Conditions

Stop before M59 if:

- Foundation verification fails.
- Any recovery route enables live action.
- Any response or store record exposes raw prompt, diff, path, body, or approval
  body.

## M59 Entry Gate

M59 may begin after:

- M58.5 docs are committed.
- `verify:foundation` passes.
- Worktree is clean.

## Workflow Skills Used and Why

- `gsd-spec-driver`: defines M59 entry gate.
- `gstack-delivery-workflow`: documents stage handoff.
- `superpowers-engineering-discipline`: keeps evidence first.

## Project Skills Used and Why

- `codexhub-release-auditor`: use for verification closeout.
- `codexhub-workflow-policy-reviewer`: use for recovery safety review.
- `codexhub-architecture-planner`: use for boundary review.

## Skills Not Used by Default

- Adapter, Electron/CDP, browser profile, and Playwright QA skills are only
  required when those surfaces change.
