# M57.8 Supervisor Task Preflight Runbook

Purpose:

- Verify and operate the Supervisor task creation shell after M57 orchestrator
  preflight wiring.

## Expected Behavior

The route should:

- Require local-control token and trusted Origin/Host.
- Reject request-body authority before route logic.
- Hash task request metadata and store a `CodexTaskIntent`.
- Resolve account, quota, client, App Server session, drift, and lease metadata
  from the store.
- Call the orchestrator preflight kernel, then store `CodexTaskRun`,
  `CodexTaskDiagnosis` when present, and hash-only leases.
- Ignore request-body approval artifacts.
- Return `directAdapterExecutionAllowed: false`, `liveExecution: false`, and
  `externalProcessStarted: false`.

## Operator Checks

1. Run `pnpm nx test supervisor`.
2. Run `pnpm nx build supervisor`.
3. Run `pnpm nx lint supervisor`.
4. Run `pnpm audit:boundaries`.
5. Run `pnpm audit:no-live-automation`.
6. Confirm `POST /tasks` responses include preflight status and dispatchAllowed
   metadata but no raw prompt, body, path, or approval artifact.

## Stop Conditions

Stop if:

- `POST /tasks` imports or calls an App Server adapter.
- A request-body approval artifact changes approval status to approved.
- The route starts a process or marks `externalProcessStarted` true.
- The route marks `liveExecution` true.
- A response or stored record contains raw prompt, diff, path, body, token,
  cookie, session, MFA, storage, or request approval artifact.

## M57.9 Entry Gate

M57.9 may begin after:

- Supervisor focused test/build/lint pass.
- Static audits pass.
- M57.8 release, review, and runbook docs are committed.

## Closeout Gates

- Focused Supervisor tests/build/lint.
- Static audits.
- Independent M57.8 commit.
