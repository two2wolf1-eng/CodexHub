# M58.4 Diagnosis Recovery Supervisor Runbook

Purpose:

- Verify Supervisor diagnosis/recovery projections and dry-run recovery shell.

## Operator Checks

1. Run `pnpm nx test supervisor`.
2. Run `pnpm nx build supervisor`.
3. Run `pnpm nx lint supervisor`.
4. Run `pnpm scaffold:health`.
5. Run `pnpm audit:no-live-automation`.
6. Confirm recovery POST responses keep `liveExecution: false`,
   `externalProcessStarted: false`, and `executionDisabled: true`.

## Stop Conditions

Stop if:

- A Supervisor route calls a capability adapter directly.
- A recovery request starts a process or live desktop/account action.
- Request-body approval changes recovery approval status to approved.
- Any response or record stores raw prompt, diff, path, body, or approval body.

## M58 Hardening Entry Gate

M58 hardening may begin after:

- Supervisor test/build/lint pass.
- Static audits pass.
- M58.4 docs and commit are complete.

## Workflow Skills Used and Why

- `gsd-spec-driver`: defines route stop conditions.
- `gstack-delivery-workflow`: documents M58 closeout gates.
- `superpowers-engineering-discipline`: keeps recovery execution disabled.

## Project Skills Used and Why

- `codexhub-architecture-planner`: use for route/kernel boundaries.
- `codexhub-contract-designer`: use for record projection checks.
- `codexhub-workflow-policy-reviewer`: use for approval and no-live checks.
- `codexhub-release-auditor`: use for verification.

## Skills Not Used by Default

- Adapter, Electron/CDP, browser profile, and Playwright QA skills are only
  required when those surfaces change.
