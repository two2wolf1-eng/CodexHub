# M55.5 Electron/CDP Observation Hardening Runbook

Purpose:

- Preserve M55 boundaries as the project moves into M56 scheduling.

## Required Checks

Before M56 starts:

1. Run `pnpm verify:foundation`.
2. Confirm M55 commits are independent.
3. Confirm health hints are advisory.
4. Confirm no Electron/CDP UI mutation path exists.
5. Confirm no real OS process enumerator is enabled by default.

## Stop Conditions

Stop if:

- A real process enumerator appears without boundary review.
- `Runtime.evaluate`, DOM mutation, click/type, screenshot, DOM snapshot, or
  network body capture is enabled.
- Raw paths, command lines, tokens, cookies, sessions, MFA, storage, prompts,
  diffs, network bodies, or DOM bodies are stored.
- Scheduler or orchestrator code treats M55 hints as authority to act.

## M56 Handoff

M56 may score accounts and clients using:

- Codex Desktop health status.
- Diagnosis hints.
- Process/endpoint/target presence.
- Console/network error counts.
- Quota/account/workspace readiness metadata.

M56 must continue to route writes through policy, approval, evidence, and audit.
