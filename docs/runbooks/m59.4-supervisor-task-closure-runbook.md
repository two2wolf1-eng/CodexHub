# M59.4 Supervisor Task Closure Runbook

Purpose:

- Provide operating guidance for the M59 Supervisor closure shell.

## Operator Checks

1. Use `GET /tasks/closures` to inspect closure metadata.
2. Use `POST /tasks/:taskId/closure` only with ids, hashes, counts, statuses,
   and CI metadata.
3. Provide changed file hashes and diff hashes only.
4. Treat branch publish and draft PR fields as dry-run plan hashes.
5. Do not include approval artifacts, authority objects, raw diff, paths, PR
   bodies, prompts, tokens, cookies, session data, MFA data, storage, command
   bodies, or response bodies.

## Stop Conditions

Stop if:

- POST returns raw body rejection.
- Any closure run reports `liveRemoteWriteAllowed: true`.
- A route begins directly invoking GitHub, verification, process, or network
  adapters.
- Store writeback includes raw closure data.
