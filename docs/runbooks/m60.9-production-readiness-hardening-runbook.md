# M60.9 Production Readiness Hardening Runbook

Purpose:

- Confirm M60 production readiness can pass the full foundation verification
  suite before final M60 closeout.

## Operator Steps

1. Confirm the worktree is clean before hardening begins.
2. Run full foundation verification.
3. Confirm scaffold, boundary, SQLite isolation, no-live-automation, skills,
   lint, test, and build checks pass.
4. Record hardening evidence in release and review docs.
5. Stop before enabling any live external probe.

## Expected Results

- Foundation verification completes successfully.
- M60 readiness, canary, drift, live-smoke gate, audit export, and E2E rehearsal
  code remains metadata-only.
- No new process, network, Browser, Electron/CDP, App Server, or GitHub boundary
  is invoked by this round.

## Stop Conditions

Stop if:

- `pnpm verify:foundation` fails.
- Any route bypasses governance/store projections.
- Any live probe, adapter call, file mutation, git write, or command execution
  is added without dry-run, policy, approval, evidence, and audit gates.
- Raw prompt, diff, path, body, schema, target, audit record, canary output,
  token, cookie, session, MFA, or storage appears in persisted output.

same no-unreviewed-live-automation boundary.
