# M61.20-M61.24 Runbook

## Operator Steps

1. Run a debug rehearsal through Supervisor only.
2. Read probes and report through GET projections.
3. If the report is `manual_checkpoint`, resolve role or workspace readiness manually.
4. If the report is `needs_adapter`, do not activate live read until M62 gates pass.
5. If the report is `no_go`, stop and review source or forbidden-path failures.

## API

- `GET /api/business-quota-debug/probes`
- `GET /api/business-quota-debug/report`
- `POST /api/business-quota-debug/rehearsals`

## Response Shape

- ids, hashes, counts, statuses, summaries, evidence refs, and audit ids only.
- `directAdapterExecutionAllowed: false`
- `executionDisabled: true`
