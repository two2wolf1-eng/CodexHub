# M75.5 Real Rehearsal Acceptance

## Summary

M75.5 adds the acceptance envelope that separates fixture-only Codex Desktop orchestration rehearsals from conditional live rehearsals. The run record now states whether a real boundary was reached, whether a live client was touched, whether Codex Desktop or an admin write was involved, and whether post-write verification completed.

## Scope

- Added metadata-only contracts for real rehearsal acceptance plans, runs, and evidence summaries.
- Added Supervisor projection under `/api/codex-desktop-orchestration/real-acceptances`.
- Added SQLite/store repositories for M75.5 acceptance records.
- Preserved M75 defaults: no generic CDP passthrough, no selector or JavaScript from request bodies, no raw prompt storage, and no credential material.

## Acceptance

M75.5 can now record one of three truthful outcomes:

- `fixture_only`: no live client was touched.
- `readiness_blocked`: live acceptance could not start because a gate, surface, authority, or runtime prerequisite was missing.
- `real_live_accepted`: the governed route reached a registered live boundary and stored metadata-only evidence.

## Verification

Focused tests cover contract parsing, forbidden body rejection, Supervisor route gates, and store round trips. Full foundation gates remain required before shipping.
