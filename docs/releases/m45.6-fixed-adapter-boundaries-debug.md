Status: completed

## Goal

Make fixed adapter boundaries harder to bypass across deployment operations, Browser actions, Electron main inspector, MCP write tools, GitHub HTTP, real policy backend, and telemetry exporter surfaces.

## Scope

- Static no-live automation audit hardening.
- Adversarial negative sentinels for fixed-path bypass patterns.

## Findings

- No new implementation defect was found in the reviewed boundary files.
- The audit already covered GitHub HTTP, policy telemetry runtime imports, direct adapter execute, and broad Browser/CDP entrypoints.

## Fixes

- Added fixed-boundary audit guards for deployment write command vocabulary, direct Browser page actions, Electron `Runtime.evaluate` text in operator surfaces, and direct MCP workspace write tool exposure from CLI/MCP source.
- Added adversarial sentinels proving the audit catches `kubectl apply`, `terraform apply`, direct Browser click, direct Electron Runtime evaluation text, and direct MCP controlled worktree write tool exposure.
- Kept existing live boundary allowlists unchanged.
