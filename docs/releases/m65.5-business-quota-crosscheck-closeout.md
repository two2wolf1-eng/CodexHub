# M65.5 Business Quota Cross-check Closeout

## GSD Spec

- Goal: close the current Business quota cross-check work before adding high-privilege admin automation.
- Scope: App Server current protocol projection, Business quota cross-check contracts/kernel/store, local reading SQLite ignore rule, and this release evidence.
- Non-scope: no new admin write automation, no browser credential capture, no privileged business cleartext store.
- Acceptance: focused contracts, business quota kernel, App Server adapter, and SQLite store tests pass; static audits pass before commit.
- Risk: high, because quota readiness gates future live dispatch and high-privilege Business automation.

## Delivery

- Added metadata-only cross-check projection between App Server quota and UI observation sources.
- Updated App Server account/rate-limit parsing for the current JSON-RPC response shape while preserving hash-only public output.
- Added SQLite metadata repository coverage for cross-check reports.
- Ignored `.codexhub/business-quota-readings/` as local runtime data so probe SQLite files are not committed.

## Boundaries

- Business quota probe data remains metadata-only in normal projections.
- Local runtime SQLite under `.codexhub/business-quota-readings/` is not source-controlled.
- No cookie, session, token, MFA, password, raw network body, or browser storage collection is introduced.
