# M60.4 Production Readiness Supervisor

Status: completed.

## GSD Spec

- Goal: expose M60 production readiness canary, drift, readiness, and audit
  projections through Supervisor.
- Scope: `apps/supervisor`, focused Supervisor tests, and
  release/review/runbook docs.
- Non-scope: no live canary execution, no App Server process calls, no
  Electron/CDP probing, no GitHub writes.
- Acceptance criteria: Supervisor focused tests/build/lint and foundation
  static audits pass.
- Hard boundaries: routes call kernel/store projections only; POST requires
  local-control token and trusted Origin/Host; raw authority and raw payload
  fields are rejected.
- Affected apps/packages: `apps/supervisor`, docs.
- Risk level: high.

## Changes

- Added `/api/production-readiness/*` read-only projection routes for canary
  tasks/runs, drift gates, readiness gates, audit export summaries, and summary.
- Added guarded `/api/production-readiness/rehearsals` POST shell that writes
  metadata-only store records through the production readiness kernel.
- Extended forbidden production payload rejection to raw canary output, raw
  schema, raw target, raw audit, raw readiness data, token, cookie, session,
  MFA, and storage keys.
- Added Supervisor coverage for ready and blocked readiness projections, raw
  body rejection, token/origin coverage matrix, and no raw payload leakage.
