# M60.2 Production Readiness Store

Status: completed.

## GSD Spec

- Goal: persist M60 canary, drift, readiness, and audit export records as
  metadata-only SQLite projections.
- Scope: `packages/store-core`, `packages/store-sqlite`, focused store tests,
  and release/review/runbook docs.
- Non-scope: no production readiness kernel, no Supervisor routes, no live
  smoke execution, no adapter or Electron/CDP changes.
- Acceptance criteria: store focused tests/build/lint and foundation static
  audits pass.
- Hard boundaries: store records contain only ids, hashes, counts, statuses,
  summaries, evidence refs, and audit ids; no raw prompt/diff/path/body/token/
  cookie/session/MFA/storage.
- Affected apps/packages: `packages/store-core`, `packages/store-sqlite`, docs.
- Risk level: high.

## Changes

- Added store-core repositories for M60 production canary tasks/runs, drift
  gates, readiness gates, and audit export summaries.
- Added SQLite JSON payload tables for the same M60 projections.
- Added a metadata-only round-trip test covering canary, drift, readiness, and
  audit export persistence plus reopen behavior.
