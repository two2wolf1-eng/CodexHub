# M60.5 Live Smoke Gate

Status: completed.

## GSD Spec

- Goal: add an approval-backed live smoke gate shell that is blocked by
  production readiness metadata.
- Scope: `apps/supervisor`, focused Supervisor tests, and
  release/review/runbook docs.
- Non-scope: no real live probe execution, no App Server process call, no
  Electron/CDP probing, no GitHub push or PR creation.
- Acceptance criteria: Supervisor focused tests/build/lint and foundation
  static audits pass.
- Hard boundaries: live smoke gate requires an existing ready readiness gate and
  approval artifact seed; it records only metadata-only canary task/run records.
- Affected apps/packages: `apps/supervisor`, docs.
- Risk level: high.

## Changes

- Added guarded `POST /api/production-readiness/live-smoke-gates`.
- The route blocks when readiness is missing, not ready, not live-smoke allowed,
  or missing approval metadata.
- Approved live smoke creates `live-smoke` canary task/run records only.
- Failed live smoke canary runs block high-risk live work through metadata.
- Extended Supervisor tests for approval waiting, ready gate success, failed
  live smoke, blocked readiness, route gate coverage, and raw payload leakage.
