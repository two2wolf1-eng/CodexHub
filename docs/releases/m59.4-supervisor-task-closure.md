# M59.4 Supervisor Task Closure

Status: completed.

## GSD Spec

- Goal: expose M59 task closure through Supervisor read-only projections and a
  guarded metadata-only POST shell.
- Scope: Supervisor route integration, test coverage, package resolution
  wiring, and lockfile update.
- Non-scope: no direct GitHub adapter execution, no real branch publish, no
  draft PR creation, no live verification process execution.
- Acceptance criteria: Supervisor focused tests/build/lint and foundation
  static audits pass.
- Hard boundaries: POST requires local-control/trusted origin through existing
  Supervisor hooks, rejects request-body authority and raw closure bodies, and
  stores only metadata-only projections.
- Affected apps/packages: `apps/supervisor`, root package resolution config.
- Risk level: high.

## Changes

- Added `GET /tasks/closures` read-only projection.
- Added `POST /tasks/:taskId/closure` metadata shell that calls the
  `task-closure-kernel`, persists closure child records, and writes task-run CI
  metadata back through the store.
- Extended `GET /tasks` to include closure projection counts/items.
- Added tests for closure recording, raw body rejection, dry-run-only GitHub
  state, and task-run writeback.
