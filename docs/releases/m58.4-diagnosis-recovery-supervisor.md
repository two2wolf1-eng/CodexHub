# M58.4 Diagnosis Recovery Supervisor

Status: completed.

## GSD Spec

- Goal: persist M58 diagnosis and recovery dry-run metadata through Supervisor
  without granting live recovery authority.
- Scope: `apps/supervisor`, `tools/scaffold-health.ts`, workspace lockfile,
  focused Supervisor tests, and M58.4 documentation.
- Non-scope: no live recovery execution, no desktop restart, no account switch,
  no terminal cleanup, no App Server adapter invocation from routes.
- Acceptance criteria: Supervisor exposes diagnosis/recovery GET projections,
  recovery POST uses diagnosis/recovery kernels when a task run exists, ignores
  request-body approval, and focused tests/build/lint plus audits pass.
- Hard boundaries: local-control/trusted origin gates stay in front of POST
  logic; responses and store records contain metadata only.
- Affected apps/packages: `apps/supervisor`, `tools/scaffold-health.ts`.
- Risk level: high, because recovery routes handle high-risk action plans even
  though execution remains disabled.
