# M45.4 Supervisor Authority Gates Debug

Status: completed

## Goal

Make late-stage Supervisor mutation coverage harder to drift by ensuring every M38-M45 route family is represented in the local-control, Origin, CORS, and authority-rejection regression matrix.

## Scope

- Supervisor route gate tests.
- Late-stage helper route drift detection.
- Documentation, orchestration, and scaffold health registration.

## Findings

- M40 release lifecycle and M41 deployment observation helper routes were registered in the Supervisor but not represented in the late-stage gate matrix.
- The existing matrix covered missing token and malicious Origin, but did not explicitly test bad local-control token values for each late-stage route.

## Fixes

- Added M40/M41 helper route families to the late-stage mutating route matrix.
- Added a route expansion helper so special route families, such as version-plan dry-run-only routes, are classified explicitly.
- Extended drift detection to discover helper-registered prefixes and fail when a new late-stage helper route is not represented in the matrix.
- Added bad-token coverage and broader caller-supplied authority/raw-body/token non-echo assertions.

## Verification

- `pnpm nx run supervisor:test --skip-nx-cache` passed.
- Full foundation gates remain required before commit.

## Rollback

Revert this round to restore the prior Supervisor gate matrix and remove the M45.4 documentation/scaffold registration.
