# M32.5 Approval Boundary Failure Hardening

Date: 2026-05-06

## Scope

This debug-only round hardened approval and boundary failure semantics for late-stage control planes.

Covered areas:

- GitHub draft PR creation
- GitHub branch publish
- GitHub remote cleanup
- Custom workflow coordination
- Production workflow recovery

## Changes

- Added explicit assertions that hash mismatch and child-record blocks do not consume approvals before a boundary is reached.
- Added explicit assertions that no GitHub requests are made before successful remote write attempts.
- Added assertions that production recovery consumes only the workflow recovery approval when coordination starts and still waits for separate child approvals.

## Safety Outcome

- No new route.
- No new provider.
- No new store repository.
- No new live boundary.
- No remote write smoke.
- Request-body approval artifacts and execution authority objects remain untrusted.
- Workflow approval still does not grant child authority.
