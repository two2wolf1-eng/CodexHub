# M60.6 Readiness Audit Export

Status: completed.

## GSD Spec

- Goal: add metadata-only production readiness audit export projection.
- Scope: `apps/supervisor`, focused Supervisor tests, and
  release/review/runbook docs.
- Non-scope: no raw audit export file generation, no network upload, no GitHub
  write, no App Server or Electron/CDP call.
- Acceptance criteria: Supervisor focused tests/build/lint and foundation
  static audits pass.
- Hard boundaries: audit export route returns manifest/export hashes and counts
  only; raw records, prompts, diffs, paths, bodies, schemas, targets, canary
  output, and credentials remain forbidden.
- Affected apps/packages: `apps/supervisor`, docs.
- Risk level: high.

## Changes

- Added guarded `POST /api/production-readiness/audit-exports`.
- The route summarizes canary, drift, and readiness records by ids/hashes/counts.
- Added raw audit export rejection coverage.
- Updated route coverage matrix so the new POST shell keeps token/origin gates.
