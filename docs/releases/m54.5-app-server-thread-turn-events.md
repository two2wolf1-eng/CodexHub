# M54.5 App Server Thread, Turn, And Events

Status: completed.

## GSD Spec

- Goal: add fixture-first App Server thread, turn, and event helpers that produce
  metadata-only mirrors and summaries.
- Scope: `packages/codex-app-server-adapter`, focused adapter tests,
  release/review/runbook docs.
- Non-scope: no real App Server process launch, real prompt dispatch, real
  event stream connection, approval bridge runtime, protocol drift runtime,
  Supervisor route wiring, Scheduler, task orchestrator, Electron/CDP
  observation, or browser observation.
- Acceptance criteria: `thread/start`, `thread/resume`, `turn/start`, and event
  ingestion require initialize first, return contract-backed metadata records,
  and do not return raw thread ids, turn ids, item ids, prompt/input/output
  bodies, diffs, paths, or request ids.
- Hard boundaries: no raw prompt, diff, path, body, token, cookie, session, MFA,
  browser storage, account credential, command payload, file payload, approval
  secret, raw schema, or raw JSONL transcript is persisted.
- Affected apps/packages: `packages/codex-app-server-adapter`, docs.
- Risk level: high, because this prepares task lifecycle observation while
  deliberately avoiding real prompt dispatch.

## GStack Plan

- Plan: extend the initialized fixture transport with thread/turn/event helpers.
- Build: map responses and event notifications into M54 mirror/summary
  contracts.
- Review: verify no private ids, prompt bodies, event deltas, diffs, or paths
  leave public outputs.
- QA: run focused adapter test/build/lint and foundation static audits.
- Ship: commit independently before approval bridge and drift runtime.
- Retro: the adapter can now rehearse task lifecycle metadata without live
  dispatch.
