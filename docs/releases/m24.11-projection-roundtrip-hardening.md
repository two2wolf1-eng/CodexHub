# M24.11 Projection Round-Trip Hardening

## Summary

M24.11 is a hardening/debug-only release candidate layer on top of the M0-M24 baseline. It adds stronger regression coverage for public projection round trips, store/list/get metadata-only behavior, late-stage approval transitions, and read-only UI/CLI/MCP drift.

## Changes

- Added shared adversarial output round-trip helpers for public metadata projection tests.
- Extended representative metadata-only tests for governance projection, operator readiness, approval history, GitHub provider summaries, review package, release candidate, custom workflow, and SQLite persistence paths.
- Added Supervisor coverage showing pre-boundary custom workflow run blocks do not consume approval, while a valid follow-up run can still consume the same approved artifact.
- Hardened `audit:no-live-automation` negative sentinels for dynamic adapter execute access, bracket fetch access, and indirect process env reads.
- Registered this round in orchestration and scaffold health.

## Boundaries

- No route, provider, store repository, live boundary, remote write path, Browser act, Electron main inspector, MCP write tool, policy runtime, or telemetry exporter was added.
- Product defaults remain conservative.
- Existing approval decision mutation remains the only UI/CLI local-control exception.
