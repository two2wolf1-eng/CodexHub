# M50.1 Supervisor Core Read Control Plane

Status: completed.

## GSD Spec

- Goal: add the first M50 Supervisor real API control-plane surface as
  metadata-only read routes.
- Scope: `apps/supervisor/src/server.ts`, `apps/supervisor/src/server.test.ts`,
  release/review/runbook docs, `.codexhub` registration, scaffold health
  registration, and the M49-M60 backlog.
- Non-scope: no new contracts, store repositories, route-to-adapter execution,
  POST mutation shells, live Browser/Electron/Codex App Server/ChatGPT Business
  operation, account operation, remote write, push, or pull request.
- Acceptance criteria: root-level `GET /capabilities`, `GET /accounts`,
  `GET /clients`, `GET /tasks`, `GET /workflows`, `GET /approvals`,
  `GET /evidence`, `GET /evidence/:id`, `GET /audit`, and `GET /audit/:id`
  return metadata-only projections; raw prompt/body/path/action data is not
  returned; focused Supervisor tests and foundation gates pass.
- Hard boundaries: no token/cookie/session/MFA collection; no raw prompt, raw
  diff, raw path, raw body, raw target, raw reason, or raw action output from the
  new routes; route handlers do not call adapters directly.
- Affected apps/packages: `apps/supervisor`, docs, `.codexhub`, and
  `tools/scaffold-health.ts`.
- Risk level: critical, because this opens the first M50 real-capability API
  surface.

## GStack Plan

- Plan: start with read routes only so route contracts can stabilize before
  mutation shells.
- Build: add root-level projections for the M49.1 capability matrix, future
  account/client/task degraded states, workflow catalog, approval counts,
  evidence refs, and audit events.
- Review: confirm responses expose only ids, hashes, statuses, summaries,
  counts, evidence refs, audit ids, and boundary booleans.
- QA: run Supervisor test/build, scaffold health, audits, foundation
  verification, diff check, and git status.
- Ship: commit independently after all verification passes.
- Retro: M50.2 can add explicit mutation-shell route tests and local-control
  route gate hardening without changing the M50.1 read contract.
