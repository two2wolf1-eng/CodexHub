# M57.3-M57.4 Orchestrator Preflight

Status: completed.

## GSD Spec

- Goal: add Codex task dispatch preflight that selects scheduler metadata,
  requires all account/client/profile/thread/worktree/task/quota leases, and
  blocks repository-root writes.
- Scope: `packages/orchestrator-kernel`, its tests, package dependency metadata,
  and no-live audit allowlist for App Server session contract vocabulary.
- Non-scope: no App Server process start, no thread/turn creation, no event
  ingestion, no Supervisor POST wiring, no real filesystem or GitHub writes.
- Acceptance criteria: orchestrator tests/build/lint pass; import boundary and
  no-live automation audits pass; preflight stores hashes/counts/status only.
- Hard boundaries: no raw prompt, diff, path, body, token, cookie, session, MFA,
  storage, account identifier, or lease secret is saved or returned.
- Affected apps/packages: `packages/orchestrator-kernel`,
  `packages/codex-scheduler-kernel` dependency edge, and
  `tools/audit-no-live-automation.ts`.
- Risk level: high, because this creates the gate that will later permit live
  App Server dispatch, but this round itself invokes no live boundary.

## GStack Plan

- Plan: reuse scheduler lease bundles and contracts instead of adding a parallel
  lock language.
- Build: add `prepareCodexTaskDispatchPreflight` with metadata-only scheduler
  selection, lease bundle, task run, and diagnosis output.
- Review: verify Supervisor/adapters are not called and live execution remains
  false.
- QA: run focused orchestrator test/build/lint and static audits.
- Ship: commit the preflight round independently.
- Retro: M57.5 can now attach a governed App Server boundary behind this gate.
