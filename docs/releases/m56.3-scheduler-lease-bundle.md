# M56.3 Scheduler Lease Bundle

Status: completed.

## GSD Spec

- Goal: add hash-only scheduler lease bundle helpers for account, client,
  profile, thread, worktree, task, and quota targets.
- Scope: `packages/codex-scheduler-kernel`, focused tests, release/review/runbook
  docs.
- Non-scope: no persistent store writes, Supervisor wiring, worktree creation,
  task dispatch, App Server calls, browser automation, or Electron actions.
- Acceptance criteria: lease bundle creates `Lease` records with target/holder
  hashes, detects active/requested conflicts, and emits preflight checks.
- Hard boundaries: no raw worktree/profile path, prompt, diff, body, token,
  cookie, session, MFA, storage, command line, network body, or lease secret.
- Affected apps/packages: `packages/codex-scheduler-kernel`, docs.
- Risk level: medium, because this introduces concurrency guard metadata without
  acquiring real external resources.
