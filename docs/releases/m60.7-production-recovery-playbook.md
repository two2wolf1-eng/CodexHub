# M60.7 Production Recovery Playbook

Status: completed.

## GSD Spec

- Goal: convert M58 diagnosis/recovery outcomes into a production recovery
  playbook for M60 readiness.
- Scope: release/review/runbook docs.
- Non-scope: no new Supervisor routes, no recovery execution, no desktop
  restart, no App Server reconnect, no account switch, no terminal cleanup.
- Acceptance criteria: docs exist, static audits pass, and no code behavior is
  changed.
- Hard boundaries: high-risk recovery remains dry-run plus approval; the
  playbook cannot bypass login, MFA, permissions, quotas, or workspace
  governance.
- Affected apps/packages: docs only.
- Risk level: medium.

## Changes

- Added a production recovery playbook that maps diagnosis states to allowed
  operator actions.
- Clarified approval requirements for login recovery, account switch, App
  Server reconnect, desktop restart, turn interrupt, terminal cleanup, resume,
  fork, and transfer.
- Documented stop conditions for raw prompt/diff/path/body/session material and
  silent authority bypass.
