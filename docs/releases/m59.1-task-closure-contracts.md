# M59.1 Task Closure Contracts

Status: completed.

## GSD Spec

- Goal: add shared M59 language for task verification, review package, GitHub
  dry-run closure, and CI writeback metadata.
- Scope: `packages/contracts` schemas and focused contract tests.
- Non-scope: no store tables, no Supervisor route changes, no real GitHub push
  or PR creation, no live verification runner changes.
- Acceptance criteria: contracts test/build/lint pass and static audits pass.
- Hard boundaries: only ids, hashes, counts, statuses, evidence refs, and audit
  ids are stored; no raw prompt, diff, path, body, token, cookie, session, MFA,
  storage, or PR body is stored.
- Affected apps/packages: `packages/contracts`.
- Risk level: medium.

## Changes

- Added task closure projection schemas for diff summary, verification, review,
  GitHub closure, and closure run.
- Added optional closure writeback ids and hashes to `CodexTaskRun`.
- Added negative tests for missing diff hashes, non-draft review readiness,
  remote write enablement, and raw metadata rejection.
