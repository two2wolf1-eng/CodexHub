# M54.2 Codex App Server Store

Status: completed.

## GSD Spec

- Goal: persist M54 App Server metadata records through `store-core` repository
  interfaces and `store-sqlite` payload JSON tables.
- Scope: `packages/store-core`, `packages/store-sqlite`, focused SQLite
  round-trip tests, release/review/runbook docs.
- Non-scope: no App Server adapter, JSONL transport, account read, rate-limit
  read, thread/turn runtime, event ingestion runtime, Supervisor route wiring,
  Electron/CDP observation, or browser observation.
- Acceptance criteria: six M54 records round-trip through SQLite, list filters
  work by status, reopened stores return the persisted records, and forbidden
  raw payload fields are rejected before persistence.
- Hard boundaries: no raw prompt, diff, path, body, token, cookie, session, MFA,
  browser storage, account credential, command payload, file payload, approval
  secret, or raw schema is stored.
- Affected apps/packages: `packages/store-core`, `packages/store-sqlite`, docs.
- Risk level: high, because this adds persistence for the future App Server
  control plane while keeping it metadata-only.

## GStack Plan

- Plan: wire the M54 contracts into store interfaces before adapters.
- Build: add six repository slots, six SQLite payload JSON tables, and focused
  round-trip tests.

  public contracts.
- QA: run focused store tests/builds and foundation static audits.
- Ship: commit M54.2 independently before M54.3 adapter scaffolding.
