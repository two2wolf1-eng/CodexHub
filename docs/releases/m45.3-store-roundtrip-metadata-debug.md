# M45.3 Store Round-Trip Metadata Debug

Status: completed

## Goal

Verify that late-stage M40-M45 control-plane records can survive SQLite save/list/get round trips without raw public-output leakage or missing migration tables.

## Scope

- Store SQLite migration initialization.
- Store SQLite round-trip tests for release lifecycle, deployment, secrets, real policy/telemetry, and controlled write records.
- Documentation, orchestration, and scaffold health registration.

## Findings

- The M44/M45 repository surfaces for real policy backend, telemetry export, Browser action, Electron main inspector, and MCP write records were wired into the Store API but did not have SQLite tables in the initializer.
- The missing tables caused `real_policy_backend_dry_runs` persistence to fail before any metadata-only assertion could run.

## Fixes

- Added SQLite tables for M44 real policy/telemetry control-plane records.
- Added SQLite tables for M45 Browser, Electron, and MCP controlled write records.
- Added a metadata-only save/list/get round-trip test covering M40 release, M41/M42 deployment, M43 secrets, M44 policy/telemetry, and M45 controlled write records.

## Verification

- `pnpm nx run store-sqlite:test --skip-nx-cache` passed after the migration fix.
- Full foundation gates remain required before commit.

## Rollback

Revert this round to remove the new table initialization and the M40-M45 store round-trip regression test.
