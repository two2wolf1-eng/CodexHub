# M59.3 Task Closure Kernel

Status: completed.

## GSD Spec

- Goal: create the M59 kernel that projects task completion into diff,
  verification, review, GitHub dry-run closure, CI, and task-run writeback
  metadata.
- Scope: new `@codexhub/task-closure-kernel`, focused tests, and scaffold
  project registry.
- Non-scope: no Supervisor route integration, no real GitHub push or draft PR,
  no direct verification process execution, no raw diff/path/body capture.
- Acceptance criteria: kernel test/build/lint, scaffold health, and static
  audits pass.
- Hard boundaries: kernel starts no process, calls no remote write, and stores
  only ids, hashes, counts, statuses, evidence refs, and audit ids.
- Affected apps/packages: `packages/task-closure-kernel`, `tools/scaffold-health.ts`.
- Risk level: medium.

## Changes

- Added a public task closure kernel package.
- Added projection helpers for diff summary, verification, review, GitHub
  dry-run closure, closure run, and `CodexTaskRun` CI/closure writeback.
- Added tests for successful closure, empty diff blocking, verification failure
  blocking, CI status writeback, and metadata-only leak checks.
