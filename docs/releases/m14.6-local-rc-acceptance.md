# M14.6 Local RC Acceptance Smoke

## Status

M14.6 validates the local-only release candidate operator path from a human acceptance point of view. It does not add runtime capability, routes, write UI, remote provider integration, push, pull request creation, account handling, or new process/network boundaries.

The smoke confirms that an operator can inspect readiness, governance projection, RC readiness, and fixture acceptance behavior with existing read-only CLI and Dashboard surfaces.

## Scope

- CLI operator smoke:
  - `codexhub doctor --json`
  - `codexhub governance runs list --json`
  - `codexhub release-candidates readiness --json`
  - `codexhub release-candidates acceptance show --json`
  - `codexhub release-candidates rehearse --fixture --scenario all-pass --json`
  - `codexhub release-candidates rehearse --fixture --scenario verification-blocked --json`
- Dashboard operator smoke:
  - `#/governance`
  - `#/readiness`
  - `#/release-candidates`
- Governance gates:
  - scaffold health
  - import boundary audit
  - SQLite isolation audit
  - no-live automation audit
  - skills audit
  - foundation verification

## Safety Confirmation

- No new Supervisor route was added.
- No new Dashboard or CLI write action was added.
- No new adapter execute path was added.
- No artifact export was invoked.
- No local-control key was read by read-only CLI commands.
- No token, cookie, session, env value, raw path, raw diff, raw PR body, raw review reason, request body, or response body was stored in public output.
- Local RC export remains disabled by default and approval-gated through the existing M14b control plane.

## Operator Interpretation

The current local RC state is understandable and intentionally conservative:

- The platform health check can explain which integrations are enabled, disabled, or blocked.
- The governance projection can still render local metadata when Supervisor-backed sources are unavailable.
- RC readiness remains `not_ready` until real, governed local RC records exist.
- Fixture acceptance can prove the happy path and blocked verification path without invoking live export, Git, Codex, Nx, Browser, Electron/CDP, MCP, network, push, or pull request creation.

## Residual Risk

- This is an operator smoke, not a production remote release flow.
- RC bundle export remains local-only and disabled unless explicitly enabled and approved.
- Dashboard route behavior is verified through automated read-only tests rather than a live browser session in this round.
- Remote provider integration, push, pull request creation, deployment, signing, and account/token handling remain out of scope.

## Rollback

Rollback for M14.6 is documentation-only: remove this release note and its scaffold-health registration. Runtime behavior is unchanged.
