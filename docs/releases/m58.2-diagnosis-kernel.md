# M58.2 Diagnosis Kernel

Status: completed.

## GSD Spec

- Goal: add a metadata-only diagnosis kernel that derives task diagnosis from
  task run, event, quota, approval, client health, and drift metadata.
- Scope: new `packages/diagnosis-kernel`, focused tests, workspace dependency
  lockfile, and M58.2 documentation.
- Non-scope: no recovery execution, no Supervisor routes, no store schema
  changes, no live desktop/App Server actions.
- Acceptance criteria: kernel covers completed, failed quota, failed auth,
  waiting approval, tool stuck, model stalled, and desktop UI frozen states;
  test/build/lint pass.
- Hard boundaries: diagnosis output contains metadata only and never stores raw
  prompt, diff, path, body, token, cookie, session, MFA, or storage.
- Affected apps/packages: `packages/diagnosis-kernel`, `pnpm-lock.yaml`.
- Risk level: medium, because the kernel informs future recovery decisions but
  performs no action.
