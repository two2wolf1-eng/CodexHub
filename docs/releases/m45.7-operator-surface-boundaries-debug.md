# M45.7 Operator Surface Boundaries Debug

Status: completed

## Goal

Make Dashboard, CLI, and MCP operator surfaces harder to regress after M45 controlled write governance.

## Scope

- CLI source-level regression coverage for exact M45 controlled write mutation routes.
- MCP production-source read-only boundary coverage.
- No-live audit sentinels for CLI token options, prefix route guards, forged authority artifacts, and raw controlled-write input payloads.
- Documentation, orchestration, and scaffold health registration.

## Findings

- No product defect was found in the current Dashboard, CLI, or MCP source.
- Dashboard mutation remains limited to the existing approval decision UI plus recovery, merge, deployment, and policy telemetry guided panels.
- CLI M45 controlled write mutations use exact Supervisor route allowlists and local-control headers sourced from the existing environment-token helper.
- MCP production source remains free of provider execution, process/network boundary startup, provider token reads, local-control token reads, and controlled worktree write tool exposure.

## Fixes

- Added CLI regression coverage proving M45 controlled write mutations use exact routes, no token flags, no authority artifacts, no raw patch/selector/text/path fields, and no prefix/substr route guards.
- Extended MCP source tests to assert the controlled worktree write tool is not exposed from production MCP source.
- Added adversarial audit sentinels for CLI `--token`, dynamic controlled-write route guards, forged approval artifacts, and raw patch payloads.

## Verification

- Focused CLI, Dashboard, MCP, and no-live audit checks are required for this round.
- Full foundation gates remain required before commit.

## Rollback

Revert this round to remove the M45.7 source tests, audit sentinels, docs, and scaffold/orchestration registration.
