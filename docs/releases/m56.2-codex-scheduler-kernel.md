# M56.2 Codex Scheduler Kernel

Status: completed.

## GSD Spec

- Goal: introduce a scheduler kernel that scores Codex accounts and clients from
  metadata-only inputs.
- Scope: new `packages/codex-scheduler-kernel`, workspace/Nx registration,
  focused tests, release/review/runbook docs.
- Non-scope: no lease acquisition, worktree lock, task dispatch, App Server
  calls, Supervisor route wiring, browser automation, or Electron actions.
- Acceptance criteria: account and client scoring covers ready, quota depleted,
  wrong account, workspace mismatch, removed, pending, frozen UI, unresponsive
  App Server, and logged-out states.
- Hard boundaries: no raw account data, raw profile path, prompt, diff, path,
  body, token, cookie, session, MFA, storage, command line, or network body.
- Affected apps/packages: `packages/codex-scheduler-kernel`, `tsconfig`,
  scaffold health, lockfile, docs.
- Risk level: medium, because this creates scheduling decisions but no runtime
  authority.

## GStack Plan

- Plan: create the package after M56.1 contracts.
- Build: add account/client scoring and account/client pool projection helpers.
- Review: confirm all outputs are hashes, statuses, scores, counts, and refs.
- QA: run focused scheduler kernel test/build/lint and foundation static audits.
- Ship: commit independently before lease bundle work.
- Retro: scheduler scoring is now reusable by Supervisor and M57 preflight.
