## GSD Spec

- Goal: rehearse M59 closure outcomes before any GitHub or verification live
  boundary is allowed.
- Scope: `task-closure-kernel` rehearsal helpers, focused tests, and release
  documentation.
- Non-scope: no real branch publish, no draft PR creation, no CI polling, no
  live verification process execution.
