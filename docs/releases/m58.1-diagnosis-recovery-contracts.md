# M58.1 Diagnosis Recovery Contracts

Status: completed.

## GSD Spec

- Goal: extend shared contracts for M58 diagnosis and recovery states while
  keeping all records metadata-only.
- Scope: `packages/contracts`, contract tests, and M58.1 documentation.
- Non-scope: no diagnosis kernel, no recovery kernel, no Supervisor route
  changes, no live recovery execution.
- Acceptance criteria: new diagnosis/recovery vocabulary parses, high-risk
  recovery requires dry-run and approval, and contracts test/build/lint pass.
- Hard boundaries: recovery records remain disabled by default and cannot store
  raw prompt, diff, path, body, token, cookie, session, MFA, or storage.
- Affected apps/packages: `packages/contracts`.
- Risk level: medium, because this changes shared language used by later
  kernels and store records.
