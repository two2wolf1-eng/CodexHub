# M45.8 Rehearsal Degraded States Debug

Status: completed

## Goal

Make operator rehearsal and degraded-state surfaces harder to regress across the M0-M45 governance baseline.

## Scope

- Dashboard route smoke coverage for governance, readiness, GitHub, workflows, deployments, secrets, policy/telemetry, Browser, Electron, and MCP views.
- Dashboard degraded-state metadata-only regression coverage.
- CLI formatter regression coverage for late release, deployment, deployment operation, and secrets rehearsals.
- Documentation, orchestration, and scaffold health registration.

## Findings

- No product execution defect was found.
- The Dashboard smoke route regression still reflected the older M32.6 surface and did not explicitly include the later deployments, secrets, policy/telemetry, Browser, Electron, or MCP views.
- The representative CLI rehearsal formatter regression did not include the M40-M43 rehearsal outputs.

## Fixes

- Expanded Dashboard operator smoke route coverage through the M45-era views.
- Added degraded-state summary checks that assert late views stay metadata-only and do not persist local-control material.
- Added CLI regression coverage for release lifecycle, deployment observation, deployment operation, and secrets governance rehearsal formatter output.

## Verification

- Focused CLI and Dashboard tests are required for this round.
- Full foundation gates remain required before commit.

## Rollback

Revert this round to remove the M45.8 tests, docs, and scaffold/orchestration registration.
