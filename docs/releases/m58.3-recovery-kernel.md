## GSD Spec

- Goal: add a recovery kernel that generates dry-run recovery metadata for M58
  without executing recovery actions.
- Scope: new `packages/recovery-kernel`, focused tests, workspace dependency
  lockfile, and M58.3 documentation.
- Non-scope: no Supervisor route integration, no live login/account/client/
  desktop/terminal/thread/worktree actions, no adapter calls.
- Acceptance criteria: low-risk wait plans stay dry-run only; high-risk
  recovery kinds require approval and remain disabled; test/build/lint plus
  audits pass.
- Hard boundaries: live action is not allowed, execution remains disabled, and
  no raw prompt, diff, path, body, or command content is stored.
- Affected apps/packages: `packages/recovery-kernel`, `pnpm-lock.yaml`.
- Risk level: high, because recovery vocabulary includes high-impact actions
  even though this round only plans them.
