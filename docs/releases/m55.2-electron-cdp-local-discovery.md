# M55.2 Electron/CDP Local Discovery Projection

Status: completed.

## GSD Spec

- Goal: add read-only Codex Desktop discovery projection for process, loopback
  endpoint, target, console, network, and health metadata.
- Scope: `packages/electron-cdp-kernel`, `packages/electron-cdp-adapter`,
  focused tests, release/review/runbook docs.
- Non-scope: no real OS process enumeration, live CDP HTTP fetch by default,
  WebSocket connection, `Runtime.evaluate`, DOM mutation, click/type, network
  body capture, Supervisor route wiring, or Scheduler integration.
- Acceptance criteria: projection returns hashes/counts/status/hints only,
  rejects non-loopback endpoints, keeps CDP boundaries uninvoked, and does not
  leak raw executable paths, command lines, window titles, target titles, or
  URLs.
- Hard boundaries: adapter remains read-only and does not start external
  processes or bypass approval-gated controlled HTTP/WebSocket runners.
- Affected apps/packages: `packages/electron-cdp-kernel`,
  `packages/electron-cdp-adapter`, docs.
- Risk level: medium, because this prepares local discovery without live local
  IO.

## Changes

- Added `createCodexDesktopHealthSnapshot` and diagnosis inference helpers to
  `electron-cdp-kernel`.
- Added Codex Desktop process-name allowlist helper.
- Added `createCodexDesktopReadOnlyDiscoveryProjection` to
  `electron-cdp-adapter`.
- Updated the Electron/CDP adapter manifest to `m55.2`.
- Added tests proving the projection keeps raw process, endpoint, and target
  details out of public output.
