# M59.2 Task Closure Store

Status: completed.

## GSD Spec

- Goal: persist M59 task closure projections as metadata-only SQLite records.
- Scope: `store-core`, `store-sqlite`, SQLite migration DDL, and focused
  round-trip tests.
- Non-scope: no Supervisor routes, no closure kernel, no live verification
  execution, no GitHub push or draft PR creation.
- Acceptance criteria: store focused tests/build/lint and static audits pass.
- Hard boundaries: store records persist ids, hashes, counts, statuses,
  evidence refs, and audit ids only; raw diff, path, PR body, prompt, token,
  cookie, session, MFA, and storage are forbidden.
- Affected apps/packages: `packages/store-core`, `packages/store-sqlite`.
- Risk level: medium.

## Changes

- Added store repositories for M59 diff summaries, verification projections,
  review projections, GitHub closure projections, and closure runs.
- Added SQLite JSON tables for the new records.
- Added metadata-only round-trip tests and leak checks.
