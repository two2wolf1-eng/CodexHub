# M24.9 Adversarial Governance Hardening

## Summary

M24.9 adds adversarial regression coverage for the existing M0-M24 governance baseline. It does not add capability, routes, providers, store repositories, live boundaries, or remote write paths.

- Strengthened `audit:no-live-automation` with in-memory negative fixtures that prove direct adapter execute calls, token env reads, process/network boundary access, and forbidden GitHub operations are caught.

- Expanded metadata-only output tests for projection/readiness/provider/approval/review package surfaces.
- Hardened local review package projection so raw diff/path-hash mistakes are converted to hash-only output.
