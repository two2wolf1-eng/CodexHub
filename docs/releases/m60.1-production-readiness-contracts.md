# M60.1 Production Readiness Contracts

Status: completed.

## GSD Spec

- Goal: establish shared M60 language for canary, drift, readiness, and audit
  export gates.
- Scope: `packages/contracts` schemas/tests and release/review/runbook docs.
- Non-scope: no store tables, no Supervisor routes, no live smoke execution, no
  Electron/CDP or GitHub adapter changes.
- Acceptance criteria: contracts focused tests/build/lint and foundation static
  audits pass.
- Hard boundaries: schemas store only ids, hashes, counts, statuses, summaries,
  evidence refs, and audit ids; no raw prompt/diff/path/body/token/cookie/
  session/MFA/storage.
- Affected apps/packages: `packages/contracts`, docs.
- Risk level: high.

## Changes

- Added `CodexProductionCanaryTask` and `CodexProductionCanaryRun`.
- Added `CodexProductionDriftGate` and `CodexProductionReadinessGate`.
- Added `CodexProductionAuditExportSummary`.
- Added positive and negative contract tests for canary failure blocking,
  unknown drift blocking, live smoke approval requirement, and raw audit export
  rejection.
