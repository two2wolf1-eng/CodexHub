# M50.2 Supervisor Route Gate Hardening

Status: completed.

## GSD Spec

- Goal: harden the Supervisor POST control-plane guard before adding future M50
  mutation shells.
- Scope: `apps/supervisor/src/server.ts`, `apps/supervisor/src/server.test.ts`,
  release/review/runbook docs, `.codexhub` registration, scaffold health
  registration, and the M49-M60 backlog.
- Non-scope: no new mutation shell, contract, store repository, adapter,
  Browser/Electron/Codex App Server/ChatGPT Business operation, account
  operation, remote write, push, or pull request.
- Acceptance criteria: mutating requests reject malicious Origin, untrusted Host,
  missing local-control token, invalid local-control token, and invalid
  preflight; trusted loopback Host and trusted loopback Origin still work;
  focused Supervisor tests and foundation gates pass.
- Hard boundaries: POST and OPTIONS stay local-control only; request-body
  approval artifacts and execution authority remain untrusted; route handlers do
  not call adapters directly.
- Affected apps/packages: `apps/supervisor`, docs, `.codexhub`, and
  `tools/scaffold-health.ts`.
- Risk level: critical, because this guard protects all later real-capability
  mutation surfaces.

## GStack Plan

- Plan: strengthen only the shared on-request guard and its focused tests.
- Build: add trusted Host validation for POST and OPTIONS while preserving the
  existing token and Origin checks.
- Review: confirm read routes remain available and no adapter path was added.
- QA: run Supervisor test/build, scaffold health, audits, foundation
  verification, diff check, and git status.
- Ship: commit independently after verification passes.
- Retro: M50.3 can add mutation shell tests on top of the hardened guard.
