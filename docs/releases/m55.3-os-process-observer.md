# M55.3 Allowlisted OS Process Observer

Status: completed.

## GSD Spec

- Goal: add an OS process observer that records only allowlisted process
  metadata summaries.
- Scope: `packages/observer-kernel`, focused tests,
  release/review/runbook docs.
- Non-scope: no built-in real OS process command, no process kill/start, no
  Electron/CDP HTTP fetch, no WebSocket, no Supervisor wiring.
- Acceptance criteria: observer requires an injected enumerator, filters by
  process-name allowlist, stores pid/path/commandLine as hashes, stores rounded
  CPU/memory/duration metadata, and returns unavailable when no enumerator is
  provided.
- Hard boundaries: no raw path, command line, token, cookie, session, MFA,
  storage, DOM, network body, prompt, diff, or process mutation is allowed.
- Affected apps/packages: `packages/observer-kernel`, docs.
- Risk level: medium, because this introduces process observation language while
  keeping the real system boundary injectable.

## Changes

- Added `AllowlistedOsProcessObserver`.
- Added `createAllowlistedOsProcessObserver`.
- Added `createOsProcessMetadataSummary`.
- Added tests for allowlist filtering, hash-only output, rounded metrics, and
  missing-enumerator unavailable behavior.
