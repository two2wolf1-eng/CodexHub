# M54.1 Codex App Server Contracts

Status: completed.

## GSD Spec

- Goal: add the shared metadata-only language for Codex App Server wire
  summaries, thread mirrors, turn mirrors, event summaries, approval bridge
  records, and protocol drift reports.
- Scope: `packages/contracts`, focused contracts tests, release/review/runbook
  docs.
- Non-scope: no App Server transport, process launch, account read, rate-limit
  read, thread start, turn start, event ingestion runtime, Supervisor route
  wiring, Electron/CDP observation, browser observation, or store table change.
- Acceptance criteria: new contracts parse metadata-only records, reject raw
  payload/path/diff/body leaks, enforce approval bridge count consistency, and
  block unknown or incompatible protocol drift from live dispatch.
- Hard boundaries: no raw prompt, diff, path, body, token, cookie, session, MFA,
  browser storage, account credential, command payload, file payload, approval
  secret, or raw schema is stored.
- Affected apps/packages: `packages/contracts` and docs.
- Risk level: high, because the contracts prepare real App Server dispatch and
  approval bridging while keeping this round implementation-free.

## GStack Plan

- Plan: extend contracts before store or adapter code.
- Build: add enums and schemas for transport, wire method, thread, turn, event,
  approval, and protocol drift metadata.
- Review: verify every record keeps payloads hashed/summarized and preserves
  governance authority outside the adapter.
- QA: run focused contracts test/build and foundation static audits.
- Ship: commit M54.1 independently before M54.2 store persistence.
- Retro: M54 can now persist App Server observations without raw wire content.
