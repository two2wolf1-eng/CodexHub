# M50.4 Supervisor Shell Hardening

Status: completed.

## GSD Spec

- Goal: harden the M50 root POST shells with degraded-store and shared-guard
  regression coverage before M51 contracts and store models are added.
- Scope: `apps/supervisor/src/server.test.ts`, release/review/runbook docs,
  `.codexhub` registration, scaffold health registration, and the M49-M60
  backlog.
- Non-scope: no product route behavior change, contract, store repository,
  migration, task model, adapter, Browser/Electron/Codex App Server/ChatGPT
  Business operation, GitHub remote write, push, or pull request.
- Acceptance criteria: root POST shells return `store-unavailable` without
  forged evidence/audit refs when persistence is disabled; missing local token,
  malicious Origin, and malicious Host are rejected before route logic; responses
  remain metadata-only.
- Hard boundaries: request-body approval artifacts and execution authority are
  never trusted; no raw prompt, diff, path, body, reason, action, token,
  credential, session, or account secret material is returned.
- Affected apps/packages: `apps/supervisor`, docs, `.codexhub`, and
  `tools/scaffold-health.ts`.
- Risk level: critical, because this protects the first root-level mutating
  control-plane shells.
