# M57.8 Supervisor Task Preflight

Status: completed.

## GSD Spec

- Goal: wire Supervisor `POST /tasks` to the orchestrator preflight shell so
  task creation records real scheduler, lease, approval, drift, and canary
  metadata before any App Server dispatch.
- Scope: `apps/supervisor`, focused Supervisor tests, and this release/review/
  runbook documentation.
- Non-scope: no Supervisor route calls to App Server adapters, no live dispatch
  from the route, no command/file approval auto-grant, no GitHub closure.
- Acceptance criteria: route rejects request-body authority, requires store,
  records `CodexTaskIntent`, `CodexTaskRun`, preflight diagnosis, and hashed
  leases, ignores request-body approval artifacts, and focused test/build/lint
  plus static audits pass.
- Hard boundaries: route responses and stored records contain only ids, hashes,
  summaries, statuses, counts, timestamps, evidence refs, and audit ids; raw
  prompt, diff, path, body, token, cookie, session, MFA, storage, and request
  approval artifacts are not stored or trusted.
- Affected apps/packages: `apps/supervisor`.
- Risk level: high, because this is the first Supervisor write shell for M57
  App Server task dispatch readiness.

## GStack Plan

- Plan: keep route logic thin and delegate dispatch readiness to
  `prepareCodexTaskDispatchPreflight`.
- Build: collect metadata projections from the store, score account/client,
  create preflight, and persist task run, diagnosis, and leases.
- Review: confirm the route never imports or calls the App Server adapter.
- QA: run Supervisor tests/build/lint and static audits.
- Ship: commit M57.8 independently.
- Retro: M57.9 should run full foundation verification before M58 begins.
