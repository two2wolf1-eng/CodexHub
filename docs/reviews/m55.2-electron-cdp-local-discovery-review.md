## Boundary Review

The M55.2 implementation preserves these invariants:

- Discovery projection does not invoke HTTP, WebSocket, or process boundaries.
- Non-loopback endpoints are not summarized as usable endpoints.
- Process and target raw values are accepted only as input and converted to
  hashes before public output.
- `Runtime.evaluate`, DOM mutation, click/type, screenshot, DOM snapshot, and
  network body paths remain forbidden.
