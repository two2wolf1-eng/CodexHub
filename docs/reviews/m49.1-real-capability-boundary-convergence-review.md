# M49.1 Real Capability Boundary Convergence Review

Status: completed.

## Findings

No product-code findings were introduced. The round adds documentation and
governance registration only.

## Review Scope

Reviewed:

- Real capability classifications for Browser, Electron, Codex App Server,
  ChatGPT Business, Git, Worktree, GitHub, Approval, Policy, Evidence, and Audit.
- Sensitive-output and authority boundaries.
- M50 Supervisor API entry gate.
- First Codex development task queue.
- Orchestration, integrations, and scaffold health registration.

Not reviewed:

- Live adapter behavior.
- Supervisor route implementation.
- Store schema implementation.
- Dashboard, CLI, or MCP runtime behavior.
- Real account, profile, Codex App Server, Electron/CDP, GitHub, or external
  process operation.

## Boundary Review

The new matrix and boundary documents preserve these invariants:

- Capability providers are not authority providers.
- Request-body approval artifacts and execution authorities are untrusted.
- Public/store outputs remain ids, hashes, counts, statuses, summaries, evidence
  refs, audit ids, and boundary booleans only.
- Token, cookie, session, MFA, raw prompt, raw diff, raw path, raw body, raw URL,
  raw trace, raw log, and raw database row content remain forbidden.
- M50 may add Supervisor shells only; direct route-to-adapter execution remains
  forbidden.

## Residual Risks

- M50 is still a critical-risk route surface and must be split into small route,
  gate, store, and test rounds.
- Codex App Server, ChatGPT Business, Chrome profile, and Electron/CDP work still
  require future protocol/readiness verification before any live use.
- The first task queue is issue-ready but not implemented by this round.

## Recommended Next Round

Start M50.1:

- Add Supervisor read routes for `GET /health`, `GET /capabilities`,
  `GET /workflows`, `GET /evidence/:id`, and `GET /audit`.
- Add mutation shell tests before adding POST implementation.
- Keep responses metadata-only.
- Do not call adapters directly from routes.
