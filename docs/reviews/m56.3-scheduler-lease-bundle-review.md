## Boundary Review

The M56.3 lease helpers preserve these invariants:

- Target keys and holder keys are hashed before they enter a `Lease`.
- `leaseSecretStored` is always `false`.
- Existing active/requested leases owned by another holder produce blocked
  leases and blocked preflight checks.
- Existing leases are never replaced or released by the helper.
- Worktree/profile paths are treated as opaque keys and are not emitted.

## Residual Risks

  projections instead of calling adapters.
- M57 must acquire real worktree authority through governance before dispatch.
- Later persistent lease storage must handle expiration and release semantics
  without exposing secrets.
