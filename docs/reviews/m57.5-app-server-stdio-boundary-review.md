## Boundary Review

- The default adapter manifest remains dry-run and does not enable live dispatch
  by default.
- External process start is contained to
  `packages/codex-app-server-adapter/src/stdio-process-boundary.ts`.
- Boundary output stores command hash and arg count only.
- The live transport property is non-enumerable so public JSON output does not
  include transport internals.
- The process boundary is blocked unless dry-run id, approval artifact,
  dispatch preflight, canary, and compatible drift are all present.
