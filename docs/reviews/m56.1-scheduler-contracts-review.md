# M56.1 Scheduler Contracts Review

Status: completed.

## Findings

No blocking findings were found in this contracts round.

## Review Scope

Reviewed:

- Account and client scheduling status enums.
- Account/client scheduler projection schemas.
- Scheduler preflight check and selection summary schemas.
- Metadata-only tests and scaffold health registration.

Not reviewed:

- Runtime account/client scoring.
- Lease acquisition or conflict handling.
- Supervisor `/accounts`, `/clients`, or `/tasks` projections.
- Real App Server dispatch.

## Boundary Review

The M56.1 contracts preserve these invariants:

- Account and client identities are represented by ids or hashes.
- Scheduler summaries store status, score, counts, evidence refs, and audit ids.
- Dispatch readiness is advisory metadata; no route or adapter authority is
  introduced.
- Raw prompt, diff, path, body, token, cookie, session, MFA, storage, profile
  path, command line, and network body remain forbidden.

## Residual Risks

- M56.2 must map real account/client states into these statuses without leaking
  raw account details.
- M56.3 must ensure leases do not store secrets or raw filesystem paths.
- M56.4 must keep Supervisor routes on store/governance projections rather than
  direct adapter calls.
- M57 must distinguish scheduler readiness from actual task success.
